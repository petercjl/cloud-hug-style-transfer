# 山与场自动化

把山与场滑雪服的旧详情页、SKU 和主图整理为商品摄影及上架详情页、主图、搜索图、分色 SKU。可复用已有摄影，输出上架 JPG、预览和交付清单。

## 安装

> 请安装 npm 包 @lumyne/shanyuchang-automation。

## 更新

> 请更新 npm 包 @lumyne/shanyuchang-automation。

## 使用

附上商品旧详情页、SKU、主图或已有摄影，并说明输出位置和本次任务范围。

> 请用山与场自动化处理附件中的商品，交付详情页、主图、搜索图和分色 SKU 到我指定的目录。

离线版式使用 Python 3、Pillow 和 NumPy。正式生图需要当前 Agent 已可使用 `toapiscli`，以及本次任务的生成授权。
