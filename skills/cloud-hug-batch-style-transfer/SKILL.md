# 2026-11-10抱抱云朵社批量风格转换

把已有详情页整理为完整分屏，再逐屏转换品牌风格。**当前原页决定内容与版式，原 Skill 的品牌文字和图库决定风格，一屏输入对应一张完整输出。** 仅讨论、审阅或更新 Skill 时不启动生图。

独立新 Skill，与本仓库的 `cloud-hug-style-transfer`（品牌升级流程，来源名 `cloud-hug-brand-upgrade`）并存。移除产品设定卡、指定模特卡、卖点重规划、套新版模板、A/B/C 选案和无字素材交付；保留原品牌摄影方法、优质图库及 SealSeek 生图、跟踪、恢复、下载和可选对照画板能力。

## 不可被参考图覆盖的约束

**摄影场景必须为四周空旷、背景连续的白色概念摄影棚。禁止保留或生成墙壁、窗户、窗框、窗帘、墙角、踢脚线、门、固定柜体、吊顶及可辨识的住宅建筑边界。旧图中已有这些结构也必须移除。不能把墙刷白、虚化墙角或只移除窗框当作完成。** 不改变原机位，用连续白色棚景替换建筑背景；通过原有位置的承托家具和织物维持生活使用关系，用少量有设计感的木质家具增加温度。细节见 [品牌摄影规则](references/brand-style.md)。

| 必须保留 | 范围 |
| --- | --- |
| 全部原文 | 标题、正文、中英文、数字、单位、色名、参数表、说明和已有标识；不增删、不改写、不擅自纠错 |
| 原版式 | 文图位置、文字层级、换行、对齐、图片框、圆角、边距、留白、模块顺序和页面比例 |
| 产品 | 颜色、形状、结构、比例、数量、材质特征、摆放朝向、遮挡和使用关系；不导入历史商品 |
| 人物及其他主体 | 原人物身份、人数、动作、表情、朝向与服装；原有动物和主要物件按原图保留，不从风格图新增 |
| 摄影关系 | 机位、景别、透视、主体占比、原有裁切、产品与人物的位置和受力；不为换棚景拉远镜头或重新摆拍 |

允许调整环境、承托家具、织物和既有装饰色的品牌配色，采用白色空间、奶白织物、低饱和浅蓝承托面、中性柔光与真实材质；家具外观可品牌化，保持其支撑关系。产品固有颜色不跟着环境换色。旧建筑结构不属于需要保留的内容，不能用“保持构图”保留住宅。新增木件仅限不改主体关系、机位和留白的必要布景，不给每个特写硬塞家具。未经要求不添加品牌 Logo、宠物或装饰文字。

## 1. 输入整理：先拼接，再按内容分屏

实际看图判断输入：

- 下载切片截断同一图片或文字：确认顺序，拼成完整长图，再分屏。
- 完整长图：直接按内容分屏。
- 已经按内容分好的旧页：检查完整性后直接使用，不重复拼切。

按 [预处理说明](references/preprocessing.md) 使用 `scripts/prepare_detail.py` 做确定性拼接和裁切。自然排序只是候选顺序；结合画面接缝检查重叠、缺片、错序和宽度。脚本不能理解语义，分屏边界必须由 Agent 查看完整上下文后决定：

1. 标题、相关文案及对应图片或信息模块保留在同一屏。
2. 无标题的独立图片完整保留为一屏。
3. 色卡合集、参数表、组合示意图作为完整模块，不拆内部小格。
4. 共用标题下的多张独立展示照：标题与首张一屏，后续无标题照片分别成屏。
5. 从模块间留白或自然边界裁切，每屏高度随内容变化；不等高切分、不截字、不截断画面、不漏内容。

原件保持不动，长图、分屏与来源坐标保存在本轮新目录。分屏明确且检查通过即可继续，无需例行选稿；只对真实缺片、顺序或归属歧义询问必要信息。多套商品分别整理，不混拼。

## 2. 分清三种参考的职责

读取 [素材索引](references/asset-index.md)，按需实际看图：

| 来源 | 唯一职责 |
| --- | --- |
| 本轮对应旧页 | 当前产品、原文、版式、人物及机位的直接依据；每次生成必须实际传入 |
| 内置 `assets/layout-pairs/` 前后对照 | 用户示范“转换前后内容与版式如何对应”；供理解保留关系，不是品牌效果基准，不默认传给生成模型 |
| 原 Skill 保留的 `assets/brand/`、`assets/approved/` 与品牌摄影文字 | 品牌空间、蓝白关系、木质家具、光线和材质的风格依据；不移植其中的商品、人物、动作或版式 |

用户后来提供的对应成图同样按其指定职责使用。示例并非所有细节都可直接照抄；如成图出现原页没有的动物、产品变化或住宅结构，不继承这些偏差。任何历史图片或文本均不能覆盖本页内容锁定与无墙无窗的棚景硬约束。

按 [品牌摄影规则](references/brand-style.md) 和 [逐屏提示词](references/prompt-template.md) 写完整提示词：记录可见产品数量与颜色、人物动作机位、全部原文保留、版式、需要清除的具体住宅结构，以及如何在原构图中完成棚景转换。文字少的页面也实际核对；信息表、首尾页不按历史页码跳过。

## 3. SealSeek 执行：每屏只生成一张

按 [媒体执行](references/media-execution.md) 使用当前 `sealseek-media` 的受管入口与能力合同，不自行调用其他生图渠道。未点名模型时使用媒体包默认模型，不因中文或比例自行换模型。当前分屏原图为第一张真实输入参考；按需附一张已查看、职责明确的原品牌正例。

授权范围内 N 屏，首次生成就是 N 个一张输出的任务，**每屏 count=1**。一屏含十个色卡也只生成一张整屏，不拆图片位、不出三案、不另加试稿、无字版或固定品牌页。用户明确要求转换且范围清楚时直接执行，不再经过产品卡或方案批准。

先校验当前模型的参考、比例和分辨率能力，再 dry-run、提交一次并立即保存任务 ID。记录每屏提示词、实际参考及职责、原图尺寸、输出与验收状态。等待/恢复同一任务；未知结果先查询，不盲目重提。额外付费重生遵循已明确授权范围，不将一张最终图理解为无限尝试。

输出完整原文与原版式整屏；原页无字时保持无字，不新增标题或标识。以原分屏比例及像素尺寸为交付目标，但提示词不保证精确像素；检查实际模型能力和下载文件。仅在不改变原比例、留白、裁切与版式时做等比尺寸整理。不能为凑尺寸拉伸、补边改版、截掉内容；无法满足时标明具体限制并保留该屏状态。

## 4. 逐屏新旧对照验收与交付

实际并排查看旧页与成图，检查：

- 全部原文逐项一致，特别是小字、数字、单位、色名和表格；OCR 只能辅助，不能替代核对。
- 版式、图片框、留白、原机位、人物动作、主体位置及裁切保持。
- 产品颜色、形状、结构、比例、数量和材质保持，无漏款、混色或额外产品。
- **逐个摄影区域检查无墙、无窗、无建筑边界**，包括多图页每一格、镜面反射和背景边缘；不能只查大图或通过文字提示词判定达标。
- 呈现连续白色概念棚景、浅蓝与奶白承托、中性柔光及合适的木质家具；原品牌方法落实且未改变当前内容。
- 文件可打开，实际尺寸、数量和逐屏对应完整。

出现住宅结构、错文、错色或结构漂移即标为待修复，不能因图片好看或生成成功判通过。可确定性恢复的原文字区域可在副本修复，但必须核对位置与边缘，不带回旧住宅背景；修复仍属于同张交付。涉及新付费生成时按实际授权处理，保留已有任务和结果。

按 [交付记录](references/delivery.md) 提供成图、逐屏对应清单和具体未完成项。每屏最终一张，原件和生成原始输出保留。仅在用户要求或本轮已授权时使用 [新旧对照画板](references/canvas-comparison.md)，不为归档重生图片或自动公开分享。
