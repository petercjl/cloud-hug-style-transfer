# 单屏风格转换提示词

用于一张已完成内容分屏的旧页。先实际查看原图，填写本页可观察到的事实；不要把占位符、未核实的产品参数或另一页的事实直接发送。每屏独立传入其完整原图，生成一张保留全部原文与版式的完整成图。

## 每次调用前的最小记录

- 屏号、原图路径、原始宽高与比例。
- 页面类型及结构：单图、图文、多格 SKU、参数表等；标题区、图片框、正文/标签区、原有标识的位置。
- 本页所有原文的核对记录，尤其数字、单位、颜色名称、英文及小字。无法辨认处先查看原图高分辨率局部，不猜写。
- 产品数量/颜色/形态/朝向/位置，人物与动物数量，原动作、衣着、视线、接触点、机位和裁切。
- 原图应移除的住宅结构，品牌浅蓝由哪个既有承托面承担，木家具如何在原构图内落实。
- 实际传入参考的顺序和职责；有序清单必须与真实调用一致。

文字核对记录帮助验收，不要求将整页长文在多个文件重复抄写。源图是全部内容的直接依据，记录不能漏写后反过来删掉图中其他文字。

## 可填写的完整指令

```text
任务：对参考 1 中的第 {屏号} 屏旧详情页做抱抱云朵社品牌风格转换。
只输出 1 张完整页面。页面原始尺寸为 {宽} × {高}，保持相同页面比例、画面边界和内容分区。最终输出应包含原页的全部文字和完整排版。

参考职责：
- 参考 1 = 当前这一屏完整原图，是全部内容、文字、版式、产品、人物和镜头的依据。
- {参考 2 等的实际文件/图号} = 原 Skill 的品牌风格正例，仅提取其白色开放棚景、奶白与低饱和浅蓝环境、设计感木家具、中性柔光、真实材料质感。不要移植其中的产品、人物、动物、文字、Logo、姿态、机位、版式或数量。

本页内容和版式锁定：
{如实描述标题/正文/英文/数字/单位/标签/表格/原有标识及各区域位置、图片框与圆角、行列、留白、边距、图文顺序。}
保留参考 1 中全部原文，逐字一致，不改写、不翻译、不增删、不补充卖点。保持原有换行、对齐、字号层级和文字位置。原有标识保留，不新增品牌 Logo、云朵或标语。页面图形的装饰颜色可转换为品牌色，但形状、位置与文字不变。

主体与镜头锁定：
{逐一写明产品数量、颜色、形状比例、材质特征、位置、朝向和合理遮挡；多格页按格位写明顺序。}
{有人的页面写原人数、身份外观、衣着、表情视线、动作、身体朝向、手部和受力接触；无人的页面明确保持无人。原图若有动物，保留原数量和位置；没有则不添加。}
{写明原机位/俯仰与观察方向、身体可见范围、主体在画框中的占比、裁切、必要承托物和前后遮挡关系。}
保持以上事实，不更换模特、不换姿势、不重新摆放商品、不改变镜头或裁切。品牌参考里的历史商品与人物不得进入此页。

必须转换的场景：
本页摄影场景是四周空旷、没有房间围合边界的白色概念摄影棚。可见背景为连续、低信息的白色无缝棚景，地面与背景在视觉上自然连续，可有柔和明暗和真实接触阴影。
原图中的 {实际可见的窗户/墙面/墙角/窗帘/固定柜体等；原图无此内容时明确无须新增} 必须清除，原位置改为开放、连续的白色棚景。
禁止出现或残留墙面、墙壁、墙角、墙地交线、踢脚线、窗户、窗框、窗洞、窗帘、门框、天花板、固定橱柜、壁龛及其他住宅建筑边界；禁止窗格投影。不允许把原房间刷白、淡化或虚化后继续保留。保留主体和版式不意味着保留这些建筑结构。
在原位置保留 {原有床/沙发/软凳/必要承托物} 的承托用途和透视关系；{具体承托面/织物} 转为低饱和浅蓝，{具体织物区域} 为奶白，与白色背景形成清楚而柔和的层次。
{适用的中景/环境页：在原家具位置以具体曲面、收腰或简洁雕塑体块的浅木家具完成替换，说明位置、用途和露出范围。不得遮挡主体/文字或改镜头。}
{近景/材质页：仅处理原裁切内可见环境，不拉远镜头，不强塞完整木家具。纯信息表：不添加摄影场景，保留原表格内容及排版，只做相容的品牌颜色和图形质感转换。}

光线、色彩与质感：
使用画外大面积扩散的中性柔光，光线来自 {与本页保留体块和接触关系相容的方向}，明亮但不过曝，柔和过渡且保留暗面、产品体积、皮肤层次和接触阴影。
品牌环境是白色/奶白、低饱和浅蓝和少量浅木本色。温度来自木材、织物与肤色，不来自黄色滤镜。商品保持参考 1 的真实颜色与配色关系，不染蓝、不漂白、不串色。
保留产品原有绒毛长度、纹理类型、缝线和受压形态；皮肤、衣物、毛绒、木材各有真实的反光与细节。不磨成塑料，不新增花纹或碎噪点，不强锐化。人物及产品接触处压陷、褶皱、重心与阴影自然一致。

输出：一张完整单屏详情页。保留原图所有图文区域、产品及人物关系，转换环境、光线和品牌风格。原页有文字就完整保留；原页本来无文字就保持无文字。不得输出方案墙、三案拼图、拆开的单格、新增页面，不得把有字原页改成无字底图。
```

用户的旧/新配对样例只供 Agent 理解内容版式保留关系，本模板不将它们作为额外模型输入。仅发送实际适用的分支，不把“近景/中景/信息表”三个互斥版本一起要求模型完成。不要写“保持所有背景和房间结构不变”，也不要一边禁止住宅、一边要求保留窗景或指定“暖白墙”。

## 提交前自检

1. 当前完整分屏原图是否真实作为第一内容参考传入，品牌正例是否来自原 Skill；配对样例是否仍只承担内容与版式对照职责？
2. 原文字、版式、产品数量和颜色、人物动作及机位锁定是否具体，是否夹入案例专属内容或旧模特要求？
3. 是否明确指出要清除的旧住宅结构，并给出“连续白色开放棚景 + 原承托关系”的替换描述，而不是只有禁止词？
4. 环境页是否指定了可见浅蓝承托与木家具位置；近景是否保持原裁切；商品本色是否独立锁定？
5. 请求是否是一屏一张、保留原有文字状态的完整页面（有字全部保留，无字不新增）？参数按媒体当前能力验证，不能用提示词声称已保证精确像素或零文字错误。

成图后按 [品牌验收](brand-style.md#逐屏与整套验收) 与原页逐项对照。出现墙窗或文字、产品漂移应如实记录为未通过，不能把提示词已写约束当成输出已满足约束。
