## 场景硬约束：无墙、无窗的开放白色概念摄影棚

每一张有摄影场景的输出都必须落实以下完整条件，不能仅在总提示词末尾追加“白色背景”：

1. **场景是四周空旷、视觉上没有房间围合边界的白色概念摄影棚。** 可见背景为连续、低信息的白色无缝棚景，主体与家具置于其中。白色棚底可以有柔和明暗渐变和真实接触阴影，不能被表现成白墙加地板的房间。
2. **禁止保留或生成墙壁、墙面、墙角、墙地交线、踢脚线、窗户、窗框、窗洞、窗帘、门及门框、天花板、固定橱柜、墙板、壁龛等住宅建筑结构。** 玻璃窗景、窗格投影及能暗示房间围合的建筑轮廓同样不符合要求。
3. **原图已有的住宅结构必须主动清除并替换为连续白色开放棚景。** 不允许只将墙刷白、将窗户淡化、把房间虚化，或以“保留原场景”为由保留建筑边界。
4. 人物、抱枕和必要承托物的位置、姿势、机位与透视继续沿用原图。清除住宅结构后，用原有床、沙发、软凳、织物等可移动布景维持承托关系；不得因此让人物悬空、产品失去支点，或改变页面阅读结构。
5. 通过少量**有设计感的木质家具**增加温度。优先在原有家具位置，以曲面、收腰、圆润边缘或简洁雕塑体块的木几、木凳等完成品牌化替换，保持相同的用途、朝向和空间角色。不能用木地板、木墙、木质窗框或固定柜体代替木家具。

环境与中景场景应明确木家具的形态、位置和露出范围。在原构图允许的空间内安排必要木件，不遮挡原文字、产品或人物，不改机位、扩大景别或挤压主体。近景、材质特写、信息表及原本几乎没有环境的画面，不为凑木件硬塞整张桌子。

提示词的场景主语使用“开放白色概念摄影棚中的床/沙发布景”，避免“温馨卧室”“概念客厅”“暖白墙”“窗边”“阳光穿过窗户”等会重新引入住宅的描述。舒适感通过人物原有行为、柔软承托、奶白织物和木材本色表达。

## 品牌色彩落实到可见物体

环境与人物互动摄影采用 **白色开放棚景 + 奶白织物 + 低饱和浅蓝承托面 + 少量浅木本色**。

- 逐屏说明浅蓝由哪个原有可见区域承担，例如沙发软包、床单、坐垫或承托织物。环境、中景中应有足以被感知的浅蓝区域，不能只写品牌名称或把浅蓝缩成不可辨认的小点。
- 奶白与浅蓝共同构成环境。不要将全部软包和织物都改成奶白，再依赖商品或页面标题承担品牌环境色。
- 商品本色、花纹与配色关系锁定；黄色、粉色、紫色等抱枕不能被统一染蓝、漂白、降低饱和度或串色。光线可以自然影响明暗，但不能改变商品辨识颜色。
- 可将原有装饰线、标签底色等转换为品牌色，保持文字、形状、位置、尺寸层级和阅读结构。不新增 Logo、云朵、标语或无关装饰，也不把原有标识替换成案例标识。
- 人物身份、动作、表情和原有衣着继续依照当前源图。原 Skill 的固定模特及奶白服装、袜子规定不在本版执行。
- SKU 合集逐格保留款色、顺序、数量与文字；功能页和材质近景不为加入浅蓝而修改产品、扩大景别或虚构道具。纯信息表保留其信息版式，无需增加摄影场景。

## 光线：明亮、有体积的中性柔光

- 采用画外大面积扩散的中性柔光。主光有可辨认的方向，过渡宽缓，保留人物、产品与家具体块；不需要可见窗户来解释光源。
- 高调不等于过曝。皮肤明暗、浅色产品层次、奶白床品纹理及接触阴影都应可见。
- 白色衣物、白色商品与白色背景通过本色、反光和柔和明暗区分，不处理成无细节的同一白块。
- 温度来自肤色、奶白材料和木材本色，不使用全图泛黄、橙色灯光或暖色滤镜。
- 排除硬窗格阴影、直射光条、突兀亮斑、舞台轮廓光及无依据的背景发光。
- 柔光不意味着各处等亮；不能为“干净”删去暗面和重量感。新光线与保留姿态的接触、遮挡关系应自洽。

## 沿用原图行为、受力与机位

先读懂原图的人正在做什么，锁定原有视线、表情、手部、身体轴线、朝向、接触点和产品参与方式。生成时描述这些已存在的关系，不重新调度人物。

肩颈、手臂、躯干和腿部保留原支点，抱枕在拥抱、倚靠、坐压处保持自然压陷，织物褶皱与阴影随受力成立。保留原图合理遮挡，不强迫产品完整正面朝镜头，也不强迫所有人物闭眼、微笑、看产品或露脸。

原图有几个人、几只动物、几件商品就保留对应数量；品牌正例和配对样例中的猫、模特或历史款式不得带入当前页。原图没有人物的页面保持无人。

机位与景别由原图决定，并具体记录身体可见范围、主体占比、产品朝向、画框裁切及环境露出量。品牌参考中的远观俯拍、贴近镜头、不同坐姿等不构成改变源图的理由。不要通过拉远镜头获得“呼吸感”，也不要通过放大商品获得“清晰卖点”。

## 空间层次与呼吸感

空间感首先来自原图已有的物距、遮挡、透视和承托关系，再配以符合距离的自然景深。保持前景、主体与后方家具的角色及位置，不另造前景遮挡、不重新摆放主体。

清除住宅结构后，后方应呈现连续、低信息的白色开放空间。呼吸感通过这个背景及原构图中的轮廓间隙建立；不能挪走商品、删除真实信息或改变图框来腾空。

环境照保留理解行为所需的场景信息；近景保护脸、手与产品接触处；俯拍、组合展示可保留较深景深。不把极浅景深设为全系列要求，不用全局模糊替代空间，也不通过模糊墙面来伪装无墙棚景。

## 材质：保留商品身份，改善摄影表达

- 按原图保留毛绒长度、绒毛方向、纹理类型、缝线、边缘与填充形态；不得将短绒改成长毛、把素面变花纹或把真实绒毛磨成塑料。
- 皮肤、衣物、抱枕、木材分别保持自然的反光、细节密度和柔软程度，不使用统一磨皮质感。
- 真实纤维、褶皱与受压变化需要保留；排除凭空添加的碎纹理、颗粒噪声、碎高光和过度锐化。
- 细节清晰度服从原图观看距离；近景有材料证据，远景不强行堆放微观纹理。
- 文字与标识的清晰度属于内容验收，不可借“风格化”改变字形、数字、颜色名称或参数。

原图、成图并排看；品牌效果同时与匹配的内置正例比较。不能凭提示词中已写要求或生成状态成功就判合格。

| 检查维度 | 实际成图要求 |
| --- | --- |
| 内容与版式 | 原文逐项对应，标题/正文/标识/数字/单位保留；图框、留白、顺序、排版和原比例不漂移 |
| 商品与人物 | 颜色、形状、材质、数量、摆放、人物身份、衣着、动作与表情符合源图；没有参考图内容混入 |

| 开放棚景 | **无窗、无墙面、无墙角和其他住宅建筑边界；原图结构已清除，未被白化或虚化掩盖** |
| 品牌环境 | 适用场景中有明确的奶白、低饱和浅蓝承托及设计感木家具，近景不被强行改景别 |
