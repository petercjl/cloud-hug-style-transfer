# 旧详情页保留模块识别

以下七张缩略图来自商品 `852689822911` 的旧「详情页」目录。它们只说明各类模块长什么样。新款的旧页内容、数量和顺序都会变化，逐屏按内容识别，不按第几张或文件名匹配。交付时取**当前款**的原文件。

| 交给设计师的屏位 | 识别特征 | 本款示例 |
|---|---|---|
| A03 卖点／功能图解 | 面料分层、防水透湿示意、功能图标及说明；本款保留面料剖层图。单纯拍摄布面水珠的旧 `11.jpg` 未入本定稿，不随 A03 交付。 | [03_04.jpg](../assets/examples/old-modules/selling-point_03_04.jpg) |
| A05 材质／填充 | 填充物实拍配保暖说明、材料名称或功能图标；示例中双手托棉絮。 | [13.jpg](../assets/examples/old-modules/material_13.jpg) |
| A06 证书／检测报告 | 带机构名、报告截图、检测项目或数值；可有多份报告并列。 | [12.jpg](../assets/examples/old-modules/certificate_12.jpg) |
| A10 产品细节 | 内衬、防雪裙、拉链、网孔、裤脚等局部特写组成宫格，常配小标签；后续切片可能只有特写而没有模块标题。 | [14.jpg](../assets/examples/old-modules/detail_14.jpg)、[15.jpg](../assets/examples/old-modules/detail_15.jpg) |
| A11 实拍展示标题 | 只有展示标题文字及可能的英文副题或装饰符号的窄条，后面通常接模特实拍。 | [17.jpg](../assets/examples/old-modules/showcase-title_17.jpg) |
| B12 尺码 | 尺码表、上衣／裤子示意线稿、身高体重推荐表；上衣裤子可能各占一张，也可能把推荐表单独成片。推荐表以身高（cm）和体重（kg）区间为两轴，交叉格填推荐尺码、组合尺码或「/」；衣长、胸围、裤长等成衣尺寸另列。 | [03_03.jpg](../assets/examples/old-modules/size_03_03.jpg) |

按原顺序连看前后切片，记录原文件与新屏号。一个模块跨两张就两张都交；一张混有其他内容就整张交，在清单注明混入的内容。同类多个候选全部交，逐个标明，由排版同事挑。某类缺失则在对应屏位标「旧页未找到」，不生成替代品。

旧切片原样复制，不裁、不修、不重编码；改用新屏号开头的交付文件名，并保留来源文件名以便反查。只有输入本身是一张长图时，才按内容边界无损分段，保留完整原图、来源坐标与组合模块。此目录中的缩略图只供识别。
