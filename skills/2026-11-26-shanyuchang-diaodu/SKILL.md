# 山与场详情页、主图、搜索图与 SKU 调度

按用户指定的类别执行。详情页除 A02 外，摄影铺满画幅，照片上不额外添加文字、LOGO 或图标，也不为它们留位置。衣服本身的标识和文字照产品图生成，不删除、不改写；胸标、配饰小标记这类小字的偏差只在清单里记录，不单独触发修正，由设计师后期处理。A02 交整屏成品。
收件后直接规划和执行，产品事实与逐屏方案只存入项目记录。蓝图是调度交给品牌摄影的内部依据。详情页在第一批出完后选稿；主图、搜索图和 SKU 走下文独立流程。

## 依赖与出图渠道

每个镜头都交给已安装的 `2026-11-24-shanyuchang-pinpai-diaoxing`。先实际打开其入口，根据当张任务读取它指定的参考、提示词和验图规范。找不到该 skill 时停下说明，禁止凭记忆代行。调度只决定拍什么、屏序和交付。
使用当前可用且已授权的生图工具，默认沿用已实测模型 `gpt-image-2.6-sunburst`。提交前核对模型、附件和所需画幅能力，同一批固定模型。不可用就说明具体缺口，不擅自换渠道、模型或产生额外费用。
蓝图画幅是排版里的照片比例，A02 按整屏比例；需要预留裁切余量时，其文字、图标、照片格和色名均须落在 4:5 安全区内。工具不支持该比例时（如 3:5、2:1、4:5），改用比它多出余量的最近可用比例：竖幅更窄的用 2:3，接近 3:4 的用 3:4，2:1 横幅用可用的最宽横幅（16:9 或 3:2）。在提示词里写清人物和动作落在目标比例的安全区内、四周留出天空或雪面供裁切，在清单备注「按 X 裁切」，由设计师在 PSD 里裁。不因比例不支持而停下，也不拉伸或补画。

所有主图及详情页 B04、B05、B07 先提交 3:4。渠道明确拒绝该比例（如 400 invalid_image_options）才改提 2:3。用实际像素标出同宽居中的 3:4 裁框，主体及整屏的全部文字、图标、表格置于框内；在清单备注「按 3:4 裁切」及裁框坐标（左、上、右、下），交设计师裁，不拉伸、不停顿。

## 详情页收件与内部规划

1. 读取全部旧详情页、SKU、主图。压缩包解到项目工作副本；格式无法解开时说明并请用户给文件夹。长图保留原件，在副本上按内容边界无损分段，记下原文件和纵坐标；已有切片按原件处理。
2. 按旧 SKU 清点色款数量，从文件名取色名，必要时对照旧多色屏文字；从旧详情页首屏识别首屏用色。
3. 逐色挑干净正面产品依据，优先全身；拍背面时补背面依据。某色缺背面，可借同款其他色的背面图只定结构，实色以本色正面为准，在清单注明。旧模特、面罩、他牌帽子、花纹雪板及森林光线均按品牌 skill 排除。
4. 按[旧模块识别示例](references/old-module-recognition.md)逐项查找；按[版式蓝图](references/detail-blueprint.md)复制到 `02_排版素材/`，文件名从新屏号起，如 `A03_卖点_旧03_04.jpg`、`B12_尺码_旧03_03.jpg`。复制后核对原件字节，多张按来源顺序登记，保留原扩展名。
5. 按蓝图及配色规则为每个生成屏、每版建立内部镜头记录，写入屏号、色款、画幅、景别、动作与机位、动作参考案例 ID、产品依据图。定稿缩略图供调度识别屏序和角色，除 A02 外不作为生成附件；A02 传 `assets/template/detail/a02.jpg` 作版式参考。
6. 用一段话告知识别到的色款、保留模块与屏位的对应结果、预计出图次数。多色为第一批 6 张加第二批 16 张，另计可能的单张修正；单色为 3 加 16，说明 A02 跳过。随即开始第一批。

## 按母版出新图

每个生成屏按蓝图写一张新照片的提示词，传入对应案例原图，不左右翻转。A01 按各版本对应的案例执行，A02 按下节规则传版式参考。动作参考图的职责在提示词里只写一句「参考图只给动作类型、机位高度、景别和情绪」。

- **保持**动作类型、机位高度（低／平／高）、景别、情绪和画幅。
- **至少改两项**，在逐屏规划里记下成图可见的变化，如人物在画面哪一侧、同一动作另一瞬间的手脚位置和重心、板的倾斜方向、水平机位、地形与背景的位置。胸上近景、面部特写、坐姿托腮等近景或静态姿势，从配饰形状、发型、脸在画面中的位置、头部转向中至少选两项。衣服结构和标识仍照产品图。
- 每项改动在提示词中写成「画面坐标 + 具体部位」。即使规划只记了「反转」，也要逐一核对双臂、双腿、板、视线、机位和人物位置，用观者的画面左右写全各项可见关系。例如「画面右臂伸向右上，画面左臂在左侧腰胯，画面右膝收高至腰部，画面左腿向左下伸展，板从画面左下斜向右上，视线朝画面右侧，机位在画面左侧低位斜拍，人物在画面中线偏左」。背面或裁切遮住的部位写明不可见。不用「更高一点」「反过来」「反转」「与参考相反」等相对指令，未规划的细节留给模型发挥。
- 光的左右按品牌 skill 逐张选。A02 的镜头变化落在照片格内，整屏版式照母版。

## 第一批与唯一选稿点

- 实际传入 a02 缩略图（只取版式、文字位置、留白和图标样式，不取旧款衣服和颜色）、覆盖各色的产品依据（可把各色 SKU 正面原照按格序并排）、MC 和光线参考 B01，可再加环境参考 B02。A02 附件以够用为准，模型上限 10 张。三版使用同一版式，只变格内人物的姿势、机位和景别，例如 v1 平视正面半身、v2 斜前方拍微转身、v3 靠近拍略低机位近景。逐字核对中文标题及引号、英文副题和每个色名，核对图标、格数、格序及图色对应。照片部分照品牌 skill 验图。文字有错与当张其他问题合并修一次，仍错在清单记录具体错字，交设计师修。
- 每张由品牌 skill 选取并实传参考、写英文提示词、生成、打开成图并验图。第一批完成后按屏号和版本展示全部候选，逐版标出仍有的偏差；相似版本标「与母版相似（待设计师决定）」并说明哪里像，直接交设计师选稿。仅重做设计师点名的版本，保留原候选与修订记录。

## 两批逐张验图

- 成图与蓝图对应案例并排比较。A01 对照当版案例，A02 只对照格内照片，固定版式不计入相似判断。发现相似，标「与母版相似（待设计师决定）」，在清单写清姿势、机位、构图、配饰或脸的位置具体哪里像。相似只报告，不自动重做、不复验，也不占该张「只修一次」。
- 仅四类错误自动修一次并复验：① 产品结构增减，如凭空多出胸前翻盖袋或后臀袋、漏掉本款一条长拉链；② 大字号他牌字样，如帽子上的 BURTON；③ 肢体或器材结构错误，如肢体粘连、多出固定器；④ 整屏成品文字错误（详情页 A02、主图 2、3、5）。同张的这些错误合并修一次，复验只核对这些错项。仍错就在交付清单标红「🔴 仍有偏差」，写清残留问题交设计师。兼有相似时照列相似清单。胸标、配饰小标记的偏差只记录。
- 与本页已生成的其他屏、选定的 A01（选定后）并排核对，动作不重复。

## 交付与核对

优先用用户指定位置。否则在旧资料目录的**同级**新建 `山与场生成_<商品编号>_<YYYYMMDD-HHMM>/`。若输入本身是独立压缩包或长图，输出与输入并列。旧资料目录保持只读。新建目录若重名则加序号，任何已有文件均不覆盖。

- `01_生成图/` 保存第一批全部候选（如 `A01_v1.png`）、另存的选定图，以及其余生成屏（如 `A04.png`、`B11.png`）。PNG 必须为真实 PNG；重做版本用新文件名并登记。
- `02_排版素材/` 保存本款保留模块的原文件副本；长图输入交按边界分出的原像素模块并标注来源区间。无该模块时登记缺项，不补造卖点、参数、证书或其他替代素材。
- `交付清单.md` 按 A01–B12 一屏一行列出屏号、处理方式、文件名（含候选与选定）、来源（生成或旧图文件名）、状态及备注。生成图逐文件标「通过 / 修正一次后通过 / 与母版相似（待设计师决定）/ 仍有偏差」，备注写具体偏差。旧图核对后标「通过」，缺项标「旧页未找到」，单色 A02 标「跳过」。注明跨片、混排、多候选及背面结构借用他色的情况。
- 第二批全部跑完后，在交付目录新建 `相似清单.md` 和 `项目记录/并排对照/`。两批每张相似图各存一张并排对照图，左为成图，右为对应案例。清单每图一行，列屏号（候选带版本）、对照案例 ID、哪里像、若重做会怎么改、并排对照图的相对路径。改法取自该屏规划，逐部位写出具体的画面左右关系。没有相似图时清单写「无」。
- `项目记录/` 保存内部镜头方案，以及每次实际英文提示词、附件顺序与逐图职责、光的选边理由、渠道、模型、请求编号、对应输出及验图结论。渠道未返回编号时如实记明。重做或修正须保留每次请求的对应关系。
