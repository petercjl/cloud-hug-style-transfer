# 山与场电商摄影与版式

版本日期 2026-11-28。日常使用从[山与场自动化](2026-11-28-shanyuchang-zidonghua/SKILL.md)进入。它确认商品与色序、安排镜头、生成带字整屏，并统一登记每张原片。[山与场品牌调性](2026-11-24-shanyuchang-pinpai-diaoxing/SKILL.md)负责无字摄影的产品事实、人物、光色和动作。[山与场版式](2026-11-28-shanyuchang-banshi/SKILL.md)离线挑旧模块、贴标、切片和导出商业图。

## 准备与交付

准备商品编号、本款旧详情页、按色序排列的 SKU、旧主图及可用的结构或侧背面依据。提供已有色名、已定稿原图与授权的项目输出目录。出图渠道为 toapiscli，模型依主入口核验；本地排版使用 Python、Pillow、numpy。三项按同级目录放置。

```text
新版项目/
  生成图/                 摄影和模型制作的带字整屏
  项目记录/               提示词、附件、回执、镜头与目检
  详情页成品/             切片、整页预览、逐屏清单及红框预览
  04_主图/                主图 JPG
  05_搜索图/              搜索图 JPG
  06_SKU/                 分色 SKU JPG
  主图搜索图SKU总览.jpg
  主图搜索图SKU交付清单.md
```

## 安装

将三个完整的 skill 目录并排复制到 `~/.codex/skills/`，或将三个压缩包解压到该目录。品牌调性副本会覆盖已装的同名旧版。让 Codex 重新加载技能后，调用 `2026-11-28-shanyuchang-zidonghua` 并给出商品项目目录。
