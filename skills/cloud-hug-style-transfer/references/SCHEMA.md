# 提示词检查知识库结构

此知识库负责提示词规划与用户反馈后的证据诊断、修订判断，采用 hybrid：流程与停点在 SKILL.md，可演进检查方法在 topics/。

到提示词检查节点才按需读取本文件、index.md、log.md最近条目，随后选择对应 queries/ 和其链接主题。维护来源 source-manifest.md 留给维护阶段。

每条知识保留稳定 ID、版本、适用范围、检查问题、证据与处理方式。来源分级：U 用户确认；E 已核验执行证据；A Agent提出的方法或原因假设；W 可追溯外部知识。A 保持暂定，不写成已证明因果。

项目内保存真实提示词、参考与任务；包内只放脱敏、可复用方法。检查输出见查询入口。新增问题先定位所属主题；有独立判断需要时再新增主题与路由。
