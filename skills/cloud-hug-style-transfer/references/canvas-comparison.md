# 产品卡与新版模板对照归档

沿用上游逐张写入、稳定元素 ID、实测尺寸与回读核验的执行方式。新流程左侧对照依据改变：产品卡阶段用该商品最清楚的旧资料图；详情图阶段用**对应新版模板或图片位**，不以旧页顺序决定新页对应。

## 本轮画板和进度

先完成媒体能力、认证、参考与参数 dry-run，再创建一次本轮画板。按商品／项目与品牌升级用途命名，例如“月亮抱枕·品牌升级”。使用当前媒体合同的 `canvas create --title 名称 --submit --json`，保存并回读真实 ID、名称与链接。

产品卡和后续详情图属于同一轮项目，沿用同一画板与进度。规划阶段不另建画板；中断后恢复已有画板，不按每次消息或每个方案重复创建。用户主动另起项目才新建；创建回执不明时先查记录与列表，不盲目再建。

在当前项目保存简短 `progress.json`，至少包含：

- 稳定 run_id、画板 ID／名称／链接；
- 产品形态／款色、卡片版本和确认状态，卖点／需求确认；
- 规划版本、已授权页清单、`assets` 或 `pages` 模式；
- 每个输出的 stage、page_id、group_id、方向、图片位、对应模板与产品卡；
- 已提交任务 ID、本地结果、URL、实际尺寸、原批次、写入状态、next_top。

只保存必要本地进度，不存凭据。用户未确认时保持相应阶段，不能因为脚本能展开清单就标记已获授权。已有人为修改或用户更正时保留历史，更新受影响记录。

## 对照源怎么选

| 输出 | 左侧对照 | 右侧 |
| --- | --- | --- |
| 产品设定卡 | 当前该款色最清楚的来源图；用户上传定稿卡时可直接记录来源关系，不为归档重新生图 | 新生成／用户确认的卡片 |
| 普通页面图片位 | 新版对应模板的摄影区域或完整模板 | 本方向独立素材 |
| 三图／四格独立素材 | 对应模板图片位的清楚参考；未裁出格位时可用整页模板，在本地清单标明图片位 | 该格位 A/B/C 素材之一 |
| 完整无字页 | 对应新版完整模板 | 本方向完整无字页 |

不把人物卡或卡片拼版样例误标成待升级商品原图。确认产品卡作为生成参考保存在任务关联中，无需每次在画板上重复铺所有卡。

默认顺序：产品卡组 → 03 → 04 → 05 → 06 → 形态展示模块 → 11 → 12 → 13 → 14 → 15。每屏按 A 的全部格位、B 的全部格位、C 的全部格位排列。每成功一张立即写入一对并核验，再处理下一张；恢复或后续单屏补做时追加到下一行，保留稳定文件键，不为重排移动已被用户编辑的旧元素。

## 保留原有确定性左右布局

用当前媒体 CLI 上传对照图，取得对照与成图的真实 URL、实际宽高；同一文件哈希未变可复用上传 URL，画板上每行仍分别显示。成图使用该任务已有 URL，不重新压缩或生图。

本包的布局助手复用上游 `comparisonRow` 函数，仅在本地算坐标，不上传、不写画板、不调用生成：

```text
node <SKILL_ROOT>/scripts/canvas-row.mjs --input <PROJECT>/row.json
```

```json
{
  "run_id": "moon-upgrade-01",
  "row_index": 1,
  "top": 0,
  "source": {"url": "https://example.com/template.jpg", "width": 1200, "height": 1600},
  "result": {"url": "https://example.com/result.png", "width": 1200, "height": 1600}
}
```

示例 URL 只能说明格式，实际用返回的真实 URL。布局为左、右各 480 单位，列间距 24；成图宽 480、高度等比；左图完整等比放入左侧范围并顶对齐；下一行留 32 单位。没有改动原始图片像素。

将返回 `batch` 保存为 JSON，使用媒体包当前 `canvas batch ID --file FILE --json` 验证，授权范围内加 `--submit` 写入；检查 verified 并通过 `canvas get` 核对元素 ID、数量、URL、比例和坐标。成功后记录 next_top。稳定 ID 由 run_id＋row_index＋source/result 构成，重复恢复同一批次不改 ID。

生成详情可放在媒体合同支持的隐藏 `generationParams` 中；只包含允许的提示词、模型、参数和参考 URL，不写私人路径、请求头或凭据，不往摄影图片加方案名称。

## 失败恢复和交付

写入不明先回读同一画板，以原批次和稳定元素 ID 恢复。使用 `--archive none` 的任务不通过默认 `task sync` 另追加一份成图；不要恢复用户删掉的元素或移动人工调整的内容。遇到并发修改时指出具体冲突。

完成时核对本轮实际授权输出与每行对应，缺失图、未确认卡、保存失败分别报告；展示真实画板链接、独立文件和模板／格位／方向清单。画板归档是交付的一部分，但归档失败不抹掉已完成的本地图片，也不能说已全部完成。
