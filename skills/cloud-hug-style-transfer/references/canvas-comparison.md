# 图片、验收与当前进度

文件名保留以兼容旧链接。交付为图片与对应清单，不建立在线画板；产品资产及详情审核 HTML 由 aigc-generation-review 生成。创作产物保存在项目目录，原始输入、提示词、请求和下载输出保留；交付副本不覆盖原图。

## 同一份项目清单

在 `manifest.json` 保存项目与工作流修订、媒体版本及以下记录；已有项目可用等价字段，不建立第二套状态：

- `confirmation`：已确认产品资产图组路径／版本、形态配色、独立尺度图及适用产品、四宫格内容和确认依据；沿用明确答案，不把空值当同意。
- `confirmedScope`：实际页面顺序、输出模式、方向（默认 A）、产品资产图组与详情图张数、费用／返工范围及授权来源。整套范围不等于允许越过看图停点。
- `scale_basis`：按 [尺度规则](product-scale.md) 保存图像、来源和适用范围；真实参数可附出处，未知保持未知。
- `plan`：每屏唯一方案、格位任务、所用产品资产图组／尺度图、模板编号与 PSD 留位；摄影方案与品牌风格参考分开记录。
- `execution`：`mode`（`stepwise` / `batch`）、`max_in_flight`（1／5）、`current_page_ids`、在途任务状态、`awaiting_user`、`last_user_decision`（决定内容、来源及适用页）。具体推进规则见 [生成节奏](planning.md)。
- `reviewReports`：阶段、运行模式、page/asset及attempt列表、输入manifest、HTML、receipt、媒体目录、覆盖范围、缺失项与警告；逐张每次一份，批量结束后统一一份。报告状态与用户确认分别记录。
- `items`：每次实际提交、下载、Agent 验收及用户看图决定；计划未提交的项不填写虚构任务 ID。

每项任务保留页面／产品组／款色／方向／格位、`promptFile`、`references`（有序路径、SHA-256、职责）、`scale_basis_ids`、`model`、`parameters`、`taskDirectory`、真实 `generationId`／`taskId`、状态与费用，以及输出路径／像素／SHA-256。参考职责为 `product-appearance`、`human-product-scale`、`model-identity`、`brand-style`；模板编号不代表模板图片已作为输入。

默认一屏一个完整页任务，`slot` 为 `page`，另记页内内容格位；仅明确拆图时分格记录。费用以回执为准，未知用 null。

资产记录与 callee 返回点见 [产品资产交接](product-assets.md)。新项目用 `confirmation.productAssetSets` 记录每款色说明、版本与独立图片；旧 productCards 只保留历史。文件校验、Agent 视觉判断、用户确认分别记录。

## 基础验收

实际查看成图，对照产品资产图组、适用尺度图、本屏方案和品牌风格，逐格核对：

- 产品外观、内部比例和相对体量，考虑透视、姿态与正常受压；
- 无墙无窗的连续白色棚景、可见浅蓝承托、适用木件与柔光；
- 页面任务、格位、留白、无排版文字及输出数量；
- 模特身份、衣着、袜子和接触受力；可见手脚的数量、归属与连接是否合理，不把不同独立格位中的手合并计数。

`review` 为 Agent 自检结论：`pass` / `needs-fix` / `pending`，记录实际观察与问题。纯微距等不适用项说明原因；明显形变、多手脚、尺度或风格偏离为需修正，未看清为待核对，不能用整体好看抵消。只在相应看图节点记录用户是否认可／要求修改／继续，不用 Agent 的 `pass` 填写用户决定。

## 更新、恢复与交付

确认、修改、提交、下载、审看后更新同一清单。逐张图片及报告展示后设置 `awaiting_user`，保留当前页；修改完成后仍等待当前页的继续决定。批量模式沿用用户的明确选择，按最多5个在途任务完成剩余授权项，结束后汇总一份HTML。

恢复先读最新用户要求与 `execution`，查询原任务、复用已完成图；正在等待就继续等待，不因清单还有未生成页而自动推进。旧清单缺少执行状态时，从真实对话恢复决定，不能把旧版“整套授权”直接当作批量选择；无法确定时只补问下一步。

最终交付目录、图片映射、验收与未完成项，区分提交数、下载数、自检通过数和用户已确认数。部分生成或等待看图时如实报告当前进度，不标记为整套完成；保留通过图片，返工仅处理指定范围。

## 本地质检与PSD交接分开

审核HTML通过aigc-generation-review的local-file-links合同引用现有原图，不内嵌、不重复复制媒体。报告、参考、提示词和回执留在本地项目，素材路径变化后按新路径重渲染。

同事用的交接目录只收录每页最终确认版本，按模板编号命名并保留原始像素，附页面对应清单、实际像素、格位职责和PSD裁切/留白注意事项。07三图和12四宫格各为一张完整页。打包前校验数量及原图/副本哈希；审核材料默认不进入压缩包。用户明确请求审核文件时，提供本地入口或另行组织所需文件，并说明素材路径依赖。
