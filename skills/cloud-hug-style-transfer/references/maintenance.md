# 版本与依赖维护

产品资产制作依赖独立包 `@petercjl/product-asset-set` >=0.1.3 及其当前配套 Skill，按 [资产交接](product-assets.md) 动态加载。详情生图继续依赖 `@petercjl/toapiscli` >=0.1.1，复用当前宿主已配置的凭据。两套工具的模型、任务恢复与费用分别按所属合同执行。

保留原项目、资产版本和确认记录。产品资产修订只重做受影响图片及下游页；技术校验不代表视觉通过。旧产品卡记录可追溯，但不会自动升级为新资产图组。

安装与升级仅同步明确选中的当前 Agent。next 测试版使用明确版本安装与包管理的目标 Skill 同步，稳定版自动更新不替代用户选择的 prerelease。源码与发布工作流是唯一维护来源。
