# 版本、来源与维护

当前包 `@petercjl/cloud-hug-style-transfer` 0.7.0。品牌业务基线是 0.6.0 与用户 2026-11-11 交接包中的品牌升级修订；保留品牌模板、人物卡、产品卡及摄影方法。迁移来源见 `../PROVENANCE.json`。

2026-11-12 本地业务修订：产品卡后建立独立人货尺度依据，默认每屏每案一张完整无字页面，并同步本地数量脚本。该修订不代表发布了新的 npm 版本，也不代表已同步其他宿主安装。

生图依赖为当前宿主独立安装的 `@petercjl/toapiscli` >=0.1.1，使用其配套 Skill、受保护凭据与任务目录恢复合同；不使用旧的媒体运行时或直连 MCP 包。品牌包不分发 API Key，也不重新导入用户已经配置好的令牌。

本包继续通过根目录 `INSTALL.md`、`UPDATE.md` 与受管 CLI 安装、核验、备份和更新；安装后的命令使用当前 Skill 的 `scripts/run.mjs`。品牌包更新与媒体包更新分别管理，尊重各自已有策略，只同步明确选中的宿主目录。

依赖检查用 `scripts/check-media.mjs`；缺少独立运行时不能只靠 `SKILL.md` 存在判定成功。宿主发现、文件完整性、模型访问和真实付费生图分别记录证据。仓库提交不等于发布 npm 新版本；部署未发布修订可从已核验的仓库副本执行受管安装。
