使用 `assets/model/character-sheet-approved-20261019.png` 作为唯一当前模特设定。用户于 2026-10-19 选定“第一张奶白素面棉袜版”，要求替换旧模特并以后以此为准。该卡包含三个角度的面部近景及正面、斜侧面、背面全身，是用户已确认的生成设定图，不是真实模特实拍。确认记录见 `model-generation.json`，仅在核对版本时读取。

生成前实际查看并传入这张卡，按其脸型、五官、棕色卷发、体态、默认家居服及袜子保持连续。原辅助人物卡和专用旧人物参考已移除，不再使用“原 KV 优先、人物卡仅辅助”的旧顺序。当前用户明确更换模特或衣着时按新要求执行；否则沿用此卡。

[完整 19 屏定稿](detail-final-20261016.md) 及旧 KV 继续提供品牌空间、光线、行为、接触与排版案例；其中旧人物面貌、裸足、短款家居服或其他衣着均不覆盖当前设定。人物与服装冲突时以本卡为准，商品仍按当次旧页或实拍变化。全部必要人物素材已内置，同事无需访问作者历史会话、私人素材库或其他技能。

## 保留可辨特征

保留已确认设定卡中年轻成年女性的自然椭圆脸、柔和脸颊与下颌、小巧鼻形、眼眉和唇形关系。深棕色蓬松自然波浪／卷发，长度越肩，两侧有松散发丝，无齐刘海。保持自然体态与头身关系，不削尖下巴、放大眼睛、减成过瘦或拉长腿。

默认完整沿用本卡衣着：奶白轻薄哑光长袖家居上衣、开口小 V 领、宽松长裤，以及奶白色素面棉袜。袜子包住脚趾、脚背、脚底、脚跟和脚踝，袜筒自然藏在裤脚内；有可见脚部时不裸足、不露脚踝。袜面平整素净，不添加明显织纹、条纹或图案，不改成拖鞋或鞋。睡眠、坐卧与站立都遵守同一规则。脚部在画外或被床品正常遮挡时保持构图，不为展示袜子改变景别、姿势或拉开遮挡。未经当前用户明确要求，不沿用旧页里的短袖短裤或其他服装，不缩短裤脚，也不添加首饰、浓妆和鞋履。

保持真实肤色和软组织明暗，不涂统一亮膜或磨皮。嘴角、眼睑和身体重心服从当下行为；正面识别照可看镜头，详情页不自动继承该视线。

## 从生活行为推导受力与表情

先用一至三句写清四件事：**她正在做什么、注意力落在哪里；重量交给哪几个接触面；哪些部位因此卸力；抱枕、衣物和身体出现什么可见反应。** 随后决定镜头如何观察，不反过来为了露产品脸、模特五官而安排手和目光。

| 行为 | 应落实的承托和状态 |
| --- | --- |
| 睡觉／休息 | 头重交给抱枕，侧脸或面颊轻陷；颈肩随高度放松，前臂由床或抱枕托住，手指松开。嘴角自然，不追加笑容；允许发丝或抱枕遮住部分脸。 |
| 阅读 | 骨盆和背部由座面、靠背承托；书与手臂有可持续的支点，目光落在书页。抱枕被夹抱或垫着，不必同时面向镜头。 |
| 发呆 | 躯干靠住承托物，肩自然下沉，手搭着而不端物；视线停在画外或近处，不必注视商品。 |
| 拥抱 | 前臂和胸腹对抱枕施加轻柔、方向明确的压力，绒面略陷、身体随之贴近；不举起陈列，也不必微笑证明喜欢。 |
| 埋脸 | 头部重量和一部分脸进入柔软表面，头颈、肩和手有可信支点；允许五官不全露。不要用“鼻嘴必须可见”“保持侧脸展示”把沉浸感拉回摆拍。 |
| 站立／抱持 | 脚、骨盆与躯干形成可信重心，手臂承接商品重量；按商品真实长宽与人体形成尺度关系，不为把产品露全而扭曲身体。 |
| 轻快活动 | 先定迈步、换重心或玩耍中的具体一瞬，允许自然笑意与身体伸展；脚不踩商品，抱持仍有支点，不把轻快拍成对镜头推销。 |

“自然、松弛、轻微笑、不刻意笑”都不能代替上述关系。表情由本屏行为决定：静谧休息不强加笑容或转脸展示，轻快互动可以有自然笑意；不能把品牌统一写成所有人都面无表情、闭眼或趴睡。静谧参考中的抬脚只是一处身体位置，不自动授权夸张踢腿或卖萌。

先看 `assets/approved/quiet-prone-user-finish.webp`：横向远一些的观看距离、面颊安顿在软物上、闭眼无展示性笑容、肩臂顺承托面放下、家具退后与大片安静空间共同成立。它提供状态与构图正例，不能证明每件道具都属于本品牌产品，亦不把其姿势套给阅读等其他行为。

其他行为按需对照完整定稿中的第 05 屏轻快活动、第 06 屏近景叠抱、第 13 屏站立尺度和第 14 屏靠坐接触，路径见上述案例索引。近景可以裁切人物与产品，先让拥抱、承托和注意中心成立；商品完整性由本屏需要说明的内容决定。

## 每次实际调用

有可见人物时，通过当前工具支持的图像输入机制实际传入 `assets/model/character-sheet-approved-20261019.png`，不能仅写“同一个女生”或只给旧 KV。明确区分输入职责：“人物身份、默认服装与袜子来自已确认设定卡；动作与用途来自当前源页；品牌成稿只提供摄影、空间、光色与排版；商品来自当次资料”。省去重复氛围图，保护当前人物和商品依据。

比较不同方案与已确认设定卡的脸型、可见五官、发长发量、身体比例、服装和素面袜；检查可见脚部及脚踝均被覆盖。衣服相同不证明身份一致，遮脸也不授权换人。允许侧脸、埋脸、局部或自然裁切，不为露全脸或展示袜子破坏行为与构图；纯产品页不传人物卡占名额。
