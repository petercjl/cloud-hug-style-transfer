# 产品尺度：直接使用独立人货图

产品卡负责外观、内部结构与比例；独立人货尺度图负责产品相对人体的体量。尺度图不拼入产品卡，不要求每张卡另配一张；同形态同规格的不同配色可以共用。

## 取得与记录依据

优先使用用户指定的尺度图，否则从已整理的旧资料中挑选产品整体与人体关系清楚的同框图；没有时请用户补充。已有适用图就直接采用，不再询问尺寸。只在图像缺失、无法辨认或适用规格存在冲突时澄清，不自行生成尺度证据。

保存图像路径、SHA-256、适用产品／规格、来源与实际限制；不把风格化示意冒充实物测量。旧资料明确提供的尺寸及出处可保存为商品事实，未知保持未知，不估读厘米或要求确认估算值。

## 规划与生成

方案只记录所用尺度图、产品和动作／支点。生图的尺寸说明限于“产品体量以第 N 张人货尺度图为准”，图号须与真实输入顺序一致；不另写厘米、身体／家具倍数、占比或产品到达的身体端点，也不从图中估算内部比例来覆盖产品卡。

动作描述说明接触和受力，例如“手臂环抱产品”；不把“产品长度到膝盖”作为大小指令。构图的画幅、格位、景别及文字留位仍按页面任务安排，它们不定义实物大小。

互动页、整体产品展示与无人陈列页实际传入适用尺度图。无人页明确只借产品体量，不带入图中人物或场景；纯材质微距不强制尺度图，产品卡阶段不用尺度图。多图整页覆盖各相关格位的依据，明确哪些格有人。输入职责和提交核对见 [媒体执行](media-execution.md)。

人物身份与衣着用模特卡，产品外观用确认产品卡，场景用品牌风格与本屏方案。动作和陈列适应产品；同规格重复实例允许正常透视差异，数量按展示目的安排，不为填满案例旧商品占位而增减尺寸。

## 看图对照

将各整体展示／互动格位与尺度图对照，考虑人物体型、姿态、距离、透视、遮挡和正常受压。区分相对体量变化与产品内部形态漂移，后者对照产品卡；不以固定像素比或猜测厘米判定通过。

偏差先核对实际图像输入及提示词是否越权规定大小；看不清则记待核对。按 [基础验收](canvas-comparison.md) 记录观察和问题，保留通过页面，修正受当前看图决定与费用范围约束。
