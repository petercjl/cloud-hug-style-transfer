# 产品尺度：使用资产组中的独立尺度图

`product-asset-set` 的 overall／structure 资产负责外观与内部比例，texture 负责材质，scale 负责产品相对人体或参照物的体量。制作及修订遵循 [产品资产交接](product-assets.md)，不再默认另做一张尺度卡。

采用已验收、适用本款规格的 scale 资产，同时记录它对应的原始实拍、用户指定图或商品规格来源、哈希与实际限制。同形态同规格不同颜色可引用同一有效尺度依据，但明确颜色只跟各款色产品资产。生成尺度图只能保留已有的相对关系，不能补作实测证据；缺少可靠来源时返回资产 Skill 请求补图。真实尺寸保存出处，未知保持未知，不估读厘米。

规划记录所用 scale 的编号、版本、规格、来源及动作／支点。生图大小只说明“产品体量以第 N 张尺度参考资产为准”，图号与真实输入一致；不另写身体／家具倍数、产品到达的身体端点或新估内部比例。

所有详情页请求必须实际传入适用 scale，包括无人陈列和纯材质微距；无人页只借体量，不带入人物或背景。每个角色的选图与提交核对见 [媒体执行](media-execution.md)。

验收分别对照全貌／结构与尺度资产，并追溯原始依据；考虑人物姿态、透视、遮挡和正常受压。区分内部形态漂移与相对体量变化，不以固定像素比或猜测厘米判定通过。尺度或其他资产修订后只复核受影响页面。

本页仅规定规划与生成时如何选用资产中的 scale，不构成独立的业务步骤。
