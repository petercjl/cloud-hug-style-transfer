# 产品尺度：以独立人货图为视觉依据

多角度产品卡负责形态、内部比例、配色与材质外观；独立人货尺度图负责产品的视觉体量。两类资料不合成一张卡，不按卡片数量一对一配套。**有适用尺度图就直接使用，不再询问厘米尺寸，也不把图片转译成另一套文字比例。**

## 从已整理资料取得依据

1. 优先使用用户已指定的尺度图；否则从旧商品资料中挑选整体体量与人体参照清楚的同框图。记录来源及严重透视、遮挡、合成或规格不明等实际限制，不把用户指定的视觉参照冒充实物测量。
2. 没有适用图时只请求补充人与产品同框的尺度照片；用户已提供则直接采用，不要求重做产品卡或给每张卡另配一张。只有图像缺失、无法辨认或无法确定适用产品／规格时才集中澄清；其他独立工作继续。
3. 旧资料已有的真实尺寸、单位、测量口径和出处继续保存为商品事实，供参数信息使用；没有则为未知。不得从未知人物身高倒推厘米数，不要求确认估读值，不生成“尺寸多大”的选项或尺寸表作为生图前置步骤。

本轮视觉生成以已选尺度图为准。已有参数不自动改写成提示词中的体量限制；只有用户明确要求参数表达时才使用有来源的数字。若资料可能属于不同规格，核对图像适用范围，不自行取平均或估算一个规格。

## 独立保存与适用范围

尺度记录只需 `id`、适用产品／规格、图像路径与 SHA-256、来源及已接受限制。已有真实尺寸可附带出处，未知用 null；不必填写身体倍数、估算厘米或计划身体比例。详细记录留在项目文档，前期集中确认只列所用图及适用范围，已有明确指定直接沿用。

- 同形态、同规格的不同配色可以共用尺度图；不同新品或大小规格不能机械继承。
- 图像独立于产品卡版本。只调整外观或配色，不自动要求补拍或重新确认尺度图。
- 保留可辨认的完整人货关系。尺度图中的人物身份、服装、场景、光色和商品表面外观不覆盖模特卡、品牌案例及产品卡。
- 参考人物与本轮模特可以不同；不直接复制跨人物的像素比。身体差异、姿态、前后距离和透视在视觉判断中考虑，不据此再编文字尺寸。

## 规划与实际生成

各页／格位记录适用的 `scale_basis_ids`、当前产品和动作／承托安排。文字可说明怎样抱、靠或支撑产品；**不写“两掌宽”“几倍脸宽”“到膝盖”“占床宽多少”等重新定义体量的指令，不以厘米、百分比或家具比例代替尺度图。** 产品自身结构与内部比例仍由确认产品卡负责。

每次调用按实际顺序说明参考职责：

| 输入 | 唯一负责的依据 |
| --- | --- |
| 本轮确认产品卡 | 外观、内部结构与比例、配色、材质 |
| 适用人货尺度图 | 当前产品相对人体的视觉体量；不借人物身份或背景 |
| 本轮模特卡 | 本次有人物画面的身份、衣着与袜子 |
| 对应屏品牌案例 | 页面任务与版式，以及概念棚景、浅蓝承托、木件、光线与空间组织 |

涉及整体体量的详情调用实际传入尺度图，包括互动页、整体产品展示及无人陈列页。提示词保留简短职责：“产品体量以第 N 张人货尺度图为准”；N 必须与本次输入顺序一致。无人页明确“尺度图仅用于体量，本次画面无人”，不传模特卡。纯材质特写不强制增加尺度图，也不据其放大裁切推断实物大小。产品卡阶段不混入人货尺度图。

多图整页一次调用覆盖各相关格位的依据，并区分哪些格有人。保护产品卡、对应品牌案例、适用尺度图及必要模特卡，先去掉重复氛围图；仍超过工具参考上限时说明实际缺口，不能用猜写数字或仅写文件路径替代图片。

动作、支点、景别和裁切适应本品体量。对应案例不提供新品大小，也不要求填满旧商品占位。多只同款保持同一规格，允许合理的远近与朝向差异；不写某只必须最大或按家具宽度确定尺寸。实例数量按本轮展示目的安排，一款可单只成立，不为复制模板中的多款阵列而强塞多只。

## 实际看图验收

把成图与本轮尺度图对照，逐个整体展示／互动格位检查：

- 是否出现无法用人物体型、姿态、距离、透视、遮挡或正常受压解释的缩小、放大或拉长；不能为了复刻模板动作而改变产品或人物大小。
- 同规格在同场、不同格位及跨页是否一致；同场产品不能仅因前后像素大小不同就判为不同规格。
- 产品形态正确是否掩盖了体量错误；无人陈列是否混入尺度图人物；参考用途是否遵守。

记录所用尺度图、实际观察及 pass / needs-fix / pending；纯微距等不适用项写明原因，不用虚构身体倍数或精确厘米证明通过。看不清的必要尺度项保持 pending。问题先核查实际参考顺序、适用规格和提示词中的额外尺寸指令，再修正相应页面；不追加估算尺寸来补救。

其余通过页面保留；额外付费返工仍受本轮授权约束。生成成功、照片好看或产品外形正确均不能代替尺度验收。
