# 产品尺度与独立的人货比例依据

在多角度产品卡完成后、整套规划前建立本轮尺度依据。产品卡负责形态、内部比例、配色与材质外观；独立的人与产品同框照片只约束实物体量。两类资料不合成一张卡，不按卡片数量一对一配套。

## 从已整理资料取得依据

1. 从用户给出的商品实拍、旧详情页、参数图或说明中提取明确规格、长宽厚、单位与来源；保留已有测量口径。软体或弯曲产品区分自然平放最大长宽、沿曲线长度与受压后的跨度，不能互换。无依据的数值保持未知，不用内置旧款参数补齐。
2. 优先从旧资料中选取可靠的人货同框图，需能辨认产品整体体量及足够的身体参照。不能因为照片好看就认作尺度证据；明显合成、严重透视、大片遮挡或不明规格的图片应标出限制。
3. 旧资料没有可靠同框图时，使用用户补充的人与抱枕实拍；用户已提供则直接使用。缺少时只请求补充这一必要资料，不自行生成比例图代替实拍，不要求重做产品卡。可继续已明确的产品识别和其他独立工作，依赖缺失尺度的互动构图待依据齐全后确定。

有可信同框图但没有明确厘米数时，可按其建立视觉尺度，不强制用户另填尺寸表；不能从未知人物身高倒推产品厘米数。若数值与照片冲突，先核对是否同一规格及透视、姿态、受压因素；仍影响判断时集中澄清，不能取平均大小。

## 独立保存与适用范围

在本轮项目资料中保存简短尺度记录：`id`、适用产品与规格、已知尺寸及出处、比例照片路径、可见身体参照、限制或待确认项。详细记录不必逐项展示给用户；统一确认时给出简短结论即可。

- 一张可靠照片可覆盖同形态、同规格的多个配色，不需要每张产品卡再拍一张。仅当有依据证明尺度相同时才能共用；不同新品或不同大小规格不能机械继承。
- 只记录适用产品与规格，不将比例图绑定为某张产品卡的配套版本。修订配色或外观卡不自动要求重拍比例图；尺寸、规格或影响体量的形态改变时再复核。
- 保留人与产品的完整参照关系，必要裁切不能把人体参照裁掉。照片里的脸、身材身份、衣着、背景、色调和商品表面外观不覆盖模特卡与产品卡。
- 不要求参考人物与当前模特是同一个人。人物体型差异、儿童与成人差异、前后距离和拍摄方向会影响观察，不能直接复制跨人物的像素比；依据不足以支持本轮人体尺度时标明限制并核对。
- 用户已经明确某张照片只用于大小时，按其职责使用，不重复索取逐卡确认，也不自动把它加入产品卡的外观生成输入。

## 规划与实际生成

每个涉及人与产品互动的方案／格位写清：本轮产品及规格、采用哪份尺度依据、当前姿态下产品相对哪些可见身体部位形成什么关系。身体参照可为躯干、肩部、手臂或头部，按实际可靠依据选取；避免只写“大小真实”“保持比例”。

尺度关系应随姿态重新表述。例如依据原图明确产品横抱时两端相对躯干的位置，再为靠坐、站立或躺卧安排合理抱法；不得把某个固定“到胸口／到膝盖”的描述套给所有新品和姿势。没有数值依据不编造百分比或厘米数。

每次实际调用分别约定输入职责：

| 资料 | 负责约束 |
| --- | --- |
| 本轮确认产品卡 | 商品外观、内部结构与比例、配色、材质 |
| 独立人货同框照片及已知尺寸 | 当前规格的实物体量、人与产品的相对大小 |
| 当前模特卡 | 模特身份、体态与默认衣着 |
| 新版模板与匹配品牌正例 | 页面职责、景别、格位、空间、光色与构图方法 |

有人物互动的生成必须实际传入适用的比例照片，并把已知规格和本案可见尺度关系写进提示词，不只引用文件路径或上一次调用。完整多图页面的一次调用需覆盖各互动格位所用产品的尺度依据；先去掉重复氛围图，不能为节省参考名额悄悄省略尺度证据，超出当前工具能力时说明具体缺口。

动作和承托适应本品大小；模板里的旧商品体量不迁移。小产品不能为填满旧长枕的位置而被放大，也不能靠缩小人物让产品显大。画面占比由景别和裁切决定，产品与人的相对体量由本轮尺度依据决定。

纯产品页／纯产品格位继续使用本轮规格与外观依据，合理保持同场商品的相对大小；整次调用没有人物时，不传入人物卡或人货照片引入人物。材质特写没有足够参照时不据此判断整体大小，跨页检查看有可比身体参照的画面。

## 成图验收与定向修正

实际对照成图与本轮尺度照片，逐个互动格位检查：

- 产品相对可见头部、躯干或手臂的体量是否符合本轮依据，抱法与接触位置是否适合该规格。
- 同规格在不同格位与跨页中（明确要求多案时也包括各备选之间）是否出现无法用姿态、景深距离、透视、遮挡或正常软体受压解释的体量变化。
- 是否为了沿用模板动作或填满构图而放大新品、拉长产品或缩小人物；外观一致不能抵消尺度错误。

同一平面、相近方向的身体参照可辅助比较，但不要求所有画面使用相同像素比，也不宣称从生成图验证了精确厘米数。记录“所用依据 → 可见尺度关系 → 通过／需处理”；看不清的尺度项标为未验证。

发生偏差时先检查规格混用、比例参考是否真正传入、提示词是否遗漏或与模板冲突，再定向调整对应姿态和输出。其余已通过页面保留；额外付费返工仍受本轮授权约束。不能用生成成功、照片好看或产品外形正确替代尺度验收。
