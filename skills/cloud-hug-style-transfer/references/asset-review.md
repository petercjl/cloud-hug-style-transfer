# 图片质检与审核报告

本节点由Cloud Hug负责选择审核范围、整理真实生成证据与质量观察，独立 `aigc-generation-review` 负责制作人工可审的离线HTML。产品资产制作仍归product-asset-set，详情生成仍归toapiscli；不复制审核模板或渲染实现。

## 动态依赖与共同交接

逻辑依赖 `aigc-generation-review`，拥有包 `@petercjl/aigc-generation-review`，最低要求0.1.1，要求manifest v1与local-file-links本地HTML render合同。从当前宿主公布的目录或配置Skill roots精确解析，完整读取当前SKILL.md；有CLI时通过skill source发现canonical source。按callee解析资源并加载当前输入合同，执行prepare及scope → evidence → manifest → render → inspect主线。

交接真实生成记录：本地结果、每次请求实际有序参考与职责、逐字提交提示词、实际模型、请求比例和分辨率、任务ID、原始请求与响应出处。保留页面/资产编号、版本、attempt及输出哈希。识别实际提交prompt的语言，英文prompt由审核Agent逐句忠实翻译为中文，按callee当前合同提供promptLanguage、promptTranslationZh和原文SHA-256绑定；在原文下方展示译文，原文及复制原文功能保持。译文依据本次真实request，不用中文规划代替翻译；缺失翻译时先补齐再交付报告。请求参数与实测输出分开记录，未知字段为null；一张输出对应一个审核区，三图页或四宫格完整页仍只占一个审核区。Agent的视觉自检发现写为简短事实观察，原因假设单独说明；不编造评分或用户认可。

报告直接引用原始本地图片/视频/音频，不内嵌、不复制媒体；保留素材位置，缺图先恢复文件或修正路径再渲染。检查模式为local-file-links，mediaDirectory为null，报告大小只随条目与文字增长。

每次新建版本化manifest、HTML和receipt，保留原图、旧报告和历史记录。接收 `{report,mediaDirectory,receipt,scope,warnings}`，核对审核区数量、参考顺序、真实提示词、参数与图片加载；按可用浏览器能力检查排版、放大及对比，未检查内容如实标注。报告入口、覆盖范围、attempt、哈希、回执与警告保存到同一项目清单。

## 产品资产阶段

完成资产图组和Agent逐张自检后、用户结果确认前运行，覆盖当前款色资产版本的全部必需候选。用户已确认且未变更图片保留确认状态；新增或修订图片继续等待。展示当前图组和报告后，返回主Skill第1步，置为 `awaiting-user-asset-confirmation` 并结束本轮；当前版本全部必需资产获用户真实确认后才进入前期集中确认。

## 详情逐张模式

`stepwise` 每次生成一张后，先下载与视觉自检，再调用审核Skill生成这张当前attempt的HTML。即使自检发现问题也保留结果及问题供审核，不因质量不佳省略报告。修订后的新attempt生成新报告，旧版本继续保留。

展示当前图片、该张报告入口和关键观察后，返回主Skill第4步当前页确认节点，设置 `awaiting_user:true` 并结束本轮，等待“修改当前图／确认并继续下一张／切换批量”。报告完成、Agent自检、用户授权生成整套均不能替代该节点的真实用户决定，等待期间不提交其他页。

## 详情批量模式

`batch` 先按最多5个在途任务完成本轮授权待生成项，批量中仍逐图进行文件检查与视觉自检；批量生成结束后只统一调用审核Skill，制作一份汇总HTML，不逐张插入等待报告或用户确认的停点。

汇总覆盖本轮选定范围的当前成果，包含之前逐张模式已确认且未变化的图片，以及本次批量新生成的图片，按页面顺序排列；已确认状态与本次新结果分别标明。每张当前输出保留对应原请求及参考，不以其他页面的提示词或参数补齐。低质量结果同样保留；旧attempt仅在明确复盘范围内加入，不能以旧项目成图顶替本轮结果。

批量结束后展示统一HTML、成功/未完成数量和主要发现，返回主Skill第5步汇总交付。失败且无图片的项在项目清单和报告范围说明中明确列出，不虚构审核区；未知任务先按原任务恢复，仍未确定时仅能交付明确标注缺口的阶段报告，不称整套完成。中途切换模式或暂停时保留所有在途与结果，待状态明确后按新的停点执行。

## 失败与恢复

依赖缺失返回DEPENDENCY_MISSING，不兼容返回DEPENDENCY_INCOMPATIBLE；保留图片与真实请求，停在报告节点。渲染或检查失败只修复记录/渲染并重用现有媒体，禁止为修复HTML自动提交付费生成。未知提交回原媒体任务查询，不重提。恢复依赖后返回当前阶段审核节点，报告有效并可访问才完成该阶段交付。

HTML是供人工审图的质检记录，不提供自动批准。查看报告不修改项目或确认状态；局部修订生成新报告、只使受影响确认失效。

## 用户指出问题后的交接

在当前图片确认节点，将用户反馈、具体页/attempt、结果、真实请求与有序参考交回主Skill的 [反馈修订分支](queries/review-revised-prompt.md)。诊断与生成由调用方负责，审核Skill仅制作报告。修订后的报告明确列出该问题实际是否改善及新发现，保留待定项；报告生成成功不代表用户接受或授权下一张。

本地审核文件、参考图、真实提示词与回执保留在项目审核目录。PSD图片交接压缩包默认只含最终确认图片、页面映射及排版说明；用户另行要求时才提供审核证据，不能将本地绝对路径报告当作可跨机器独立分享的文件。
