# 来源与覆盖

来源类型 W/U/E/A：W 可追溯外部知识，U 用户确认，E 核验执行证据，A Agent判断或假设。

覆盖：bootstrap；本次按用户要求建立内置知识库，无外部Wiki依赖。

- U：集中生成提示词后检查；图片出错后，重写提示词也用同一知识库自检；条目逐次完善。
- U：参考产品的结构与连接关系保持一致，场景和动作适应产品。
- E：核对过一次真实请求，已有通用结构锁定语句；成图仍被用户判为产品错误。私有请求、原图和审核记录保存在项目，不进入分发包。
- A：沿身体布置的动作指令、强遮挡、新机位及风格参考可能共同增加连接关系误读风险；尚无对照实验归因。

- U：反馈后先检查实际提示词与参考图，解释诊断，再局部修订、自检并在授权内生成与再验收；不将所有错误一律归因于提示词。
- U：将物体承托与空间边界纳入按需检查，使用正向空间关系表达。
- E：一组保留完整请求与结果的修订案例表明，补清家具承托地面和软垫边界后，可见支点落在地面。
- A：这是一组案例证据，尚不足以确定唯一因果或通用成功率。

缺口：无经过验证的通用构图阈值；提示词检查不能保证模型成图。新增规则需有适用范围、证据和反例，不能把单次构图固定成全局模板。

重新编译边界：用户确认新方法、执行证据推翻原因假设、参考合同或生成流程变化时，修改对应主题与路由、提升版本、更新本记录，并使受影响的项目检查回执失效。
