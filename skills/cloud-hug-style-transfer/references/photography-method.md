# 摄影方法论：柔光生活叙事摄影

> 本章沿用上游柔光生活叙事摄影方法，适用于产品确认后的详情页规划与生成。页面任务来源已改为指定新版模板；产品资产阶段按 product-asset-set 当前合同生成独立图组。


## 固定品牌风格

**Soft Lifestyle Editorial Photography（柔光生活叙事摄影）**。详情页提示词固定包含：**无墙无窗的白色／奶白连续无缝概念摄影棚、低饱和浅蓝的可见承托面、少量有设计感的木质家具，以及画外柔和扩散光。** 浅木增加温度，商品保持本色。

沙发、床铺和织物是棚内精选布景；背景与地面连续，不出现住宅墙面、墙角、踢脚线、门窗、大面积木地板或窗格投影。浅蓝必须落实到画面可见的床面、沙发、软垫或织物，不能只写在风格名称里。

中远景交代承托面与少量木件；近景可只露家具局部；纯材质微距按必要裁切，不为凑环境元素拉远镜头。产品资产按独立用途组织，摄影方法用于详情页。

以自然行为、可信受力、柔和光线、空间层次和真实材质表达拥抱与陪伴。摄影任务与品牌风格同时成立，已认可的景别与方案保持，品牌修正只调整其环境表现。

## 规则职责

| 依据 | 职责 |
| --- | --- |
| 页面映射与新版模板 | 规划阶段确定每屏任务、景别、格位与 PSD 留位；12 页按确认卖点 |
| 本轮产品资产图组 | 产品形态、内部比例、颜色与材质 |
| 资产组中的相对尺寸图 | 相对体量，详见 [尺度规则](product-scale.md) |
| 模特卡 | 人物身份、体态与衣着 |
| 本章与品牌案例 | 固定棚景、蓝白配色、木件、光线和材质气质；案例在生图中仅作风格参考 |

页面任务和构图由本轮方案落实。案例中的人物动作、家具坐标、商品数量与占位不直接继承；商品资料中的旧住宅环境不覆盖品牌棚景。

## 摄影任务识别

### 从指定新版模板确定共同设计任务

先识别本屏希望观众理解什么、感受到什么，以及原摄影通过哪些关系完成这一目的，再确定品牌转换后的摄影任务。

识别时区分：

- **需要继承的设计依据**：本屏目的、有效景别、主体分量、关键使用关系、必要承托关系，以及已经确认的图文职责。
- **需要品牌化的视觉条件**：空间、光线、色彩、人物身份与衣着、家具选择、材质表现。
- **可以重新设计的表现方式**：身体轴线、观察方向、主体位置、承托面的展开方式、前景遮挡和低信息区域的形态。

保留指定新版模板立意时，应保留让任务成立的关系，不默认逐物复制全部姿势和物体坐标。用户明确锁定的动作、布局或机位仍按要求保留。

分析整页时区分摄影框、叠字区和图外文字栏。拆图只输出摄影框，保留框内必要文字安全区，不把图外文字栏印进独立素材；完整无字页保持模板分区和留位。按 brand-layout.md 执行。

景别不能只写“中景”“近景”等名称，还应明确：

- 人物大致保留哪些身体范围；
- 人物与产品组合在摄影区中的分量；
- 需要看见多少承托面和环境，才能理解使用关系。

这些条件用于保持观看距离与信息量，用户明确要求多个备选时，不要求各案使用完全相同的裁切坐标。

“首屏”“主KV”“详情页”只说明页面用途，不自动决定摄影类型。生活叙事首屏继续使用生活摄影；漂浮、失重、幻想等表达，仅在当前任务明确要求或已经确认时采用。

**概念棚景描述空间如何搭建；失重、漂浮描述具体创意。两者不能互相替代。**

### 根据共同任务选择摄影方式

| 屏职责 | 摄影任务 | 可参考的镜头语言 | 关键调度 |
|---|---|---|---|
| 整体使用关系、环境展示 | 环境主视觉 | 35–50mm，f/3.5–5.6 | 组织人物、产品与承托物的整体关系，保留适合本屏的环境和低信息区域 |
| 生活互动、日常行为 | 舒适互动生活照 | 约50mm，f/2.8–4 | 人物休息、阅读、倚靠或拥抱，动作服务于当下活动与舒适感 |
| 情绪近景、亲密体验 | 柔软触感近景 | 70–85mm，f/2–3.5 | 注意力落在脸颊、手臂与产品的接触处，保留理解姿态所需的身体或承托物局部 |
| 材质、工艺与接触细节 | 材料细节摄影 | 近摄视点，清晰范围服从材料证据 | 表现真实纹理、绒毛方向与局部压陷，可以只拍产品或手部 |
| 俯拍、休息组合 | 俯视生活构成 | 35–50mm视角，适当较深景深 | 利用身体姿态、物体方向、间隙与承托关系组织画面 |

以上参数用于描述预期透视与景深，不作为固定模板，也不能代替具体的观看距离与裁切说明。

**同一屏的多个备选，先共同确定摄影任务与景别，再分别设计表现方式。不能逐案各选一种任务，拼成环境照、触感特写和产品展示。**

尺寸、SKU及明确的结构展示页优先保证商品信息清楚，不强制套用生活动作或情绪摄影。

## 品牌案例的选择与使用

规划时查看对应模板，理解本屏任务、观看关系和 PSD 框位。生图时继续使用现有详情页案例作风格参考，选择与本屏摄影类型和景别相容的图片，并记录实际文件；不强制每次上传对应的整页原图。

提示词明确“第 N 张仅参考品牌棚景气质、蓝白配色、木质家具设计语言、柔光和材质表现；具体构图按本屏方案”。不把原人物姿态、沙发／木几坐标、旧商品数量与摆位重述为必须复制的条件。

参考图不能覆盖本章固定品牌基准、当前产品资产图组或模特卡；已有图像可表达的风格无需逐物复述。页面格位与留白用本轮方案说明，摄影内部的动作、家具和产品组织保留设计空间。明确要求多案时，共享相容的品牌风格依据。

## 人物与空间调度原则

- 先确定人物正在做什么、为什么需要抱枕，再安排手部、脸颊、视线与产品朝向。
- 人物的注意力停留在当下行为中，不以举起商品、展示性微笑或主动面向镜头来证明喜欢产品。
- 睁眼、闭眼、自然笑意和局部露脸均由行为决定，不固定为同一种表情。
- 肩颈、手臂、躯干与腿部具有可信的重心和支点；接触处保留合理压陷、褶皱与阴影。
- 产品通过承托、倚靠、拥抱等关系参与生活，允许合理遮挡与裁切，不强求每张展示完整正面。
- 家具与织物承担支撑身体、承托产品和组织空间的作用，按已确定的景别选择露出范围。
- 环境与中景生活摄影中，安排少量经过选择的木质家具，以曲面、收腰或简洁雕塑体块增加温度与设计感。明确它的位置和作用，不用任意木色小摆件代替。
- 近景可仅保留家具局部，不为塞入完整木几而拉远镜头。
- 商品保持当前资料中的形态、比例、颜色、材质与数量，不复制风格参考中的历史SKU。
- 人货相对大小由本轮资产组的尺度依据确定；人物动作适应产品规格，不能通过放大新品或缩小人物来复刻模板中的拥抱范围。参考照片与当前模特不同，不代表可以省略尺度依据或直接照搬跨人物像素比。

生活偶然感来自可理解的身体状态：肩颈卸力、手指松弛、头部重量自然交给承托物、织物随受力形成褶皱。不要只用“闭眼”“放松”概括人物调度，也不为制造偶然感添加无关物件或杂乱痕迹。

同样是躺卧拥抱，仍可以通过身体轴线、头枕位置、承托面方向和摄影机视点形成不同方案。动作相同不等于构图必须相同。

木几、花瓶或少量绿枝本身不构成住宅化证据。应判断整体是否仍是连续棚底上的精选布景，而非通过普通居室构造补成完整房间。

## 光线与色彩

### 光线

- 采用画外大面积扩散的中性柔光。主光具有可辨认的方向，明暗过渡宽缓，保留人物、抱枕和家具体块。
- 高调摄影不等于过曝。明亮的同时保留皮肤明暗、织物纹理、浅色产品层次与接触阴影。
- 白色衣物、床品与产品依靠本色、反光特性和柔和明暗区分，不处理成等亮的纯白色块。
- 避免硬窗格投影、直射光条、突兀光斑、舞台式轮廓光和全图泛黄。
- 温度主要来自奶白材料、肤色与木材本色，不通过黄色照明表达。
- 柔和不等于各方向等亮。不能为了“干净”消除全部暗面与体积。

### 色彩

**环境与人物互动摄影以“奶白＋低饱和浅蓝”为共同环境基础，少量浅木本色增加温度，商品本色成为局部视觉重心。**

每案须明确浅蓝由哪个可见物体承担，例如床面、沙发软包、床单或织物。浅蓝应具有足以被感知的可见范围，与人物和产品形成实际关系，不仅存在于画外设定或角落中无法辨认的小点。

不得把全部床面、软包和织物都指定为奶白，同时只在总纲中保留“品牌浅蓝”的描述。

商品颜色鲜明时，控制环境饱和度与装饰竞争，保留浅蓝环境基础。不能把“商品是色彩重心”执行成“场景只允许出现商品这一种有彩色”。

商品颜色不承担替代品牌环境色的职责，也不为适配品牌配色而改变商品本色。

材质近摄与功能展示按必要裁切保留合理的品牌线索，不为加入大面积浅蓝而改动商品、扩大景别或增加无关道具。

多个备选共同保持这套光色基础，不通过改变色温、改成硬光或删除浅蓝环境来制造方案差异。

## 空间层次与景深

空间感优先通过物距、遮挡、透视、尺寸变化及承托关系建立，再安排符合实际距离的自然退焦。

每个方案都要具体说明：

- 摄影机与主体之间有什么；
- 人物和产品由哪里承托；
- 哪些物体处于更后方；
- 这些关系如何引导观看，哪些位置需要清楚。

不能仅用“前中后景”“自然虚化”或“真实景深”代替空间安排。

环境与互动摄影优先利用床沿、织物、软凳或家具局部组织前景。需要遮挡时，明确前景物、进入方向、遮挡对象，以及仍需保持可读的脸部、手部和产品接触位置。

前景可以清晰，也可以退焦。其作用首先是建立距离、形成观看入口或平衡构图，不是制造一团模糊色块。

当前任务明确要求前景遮挡时，每案均须落实，但可以采用不同的进入路径与物体关系。无需设置前景遮挡时，也应通过物距、叠压或透视建立可读空间。

环境摄影保留必要场景信息；互动摄影保护动作与接触；情绪近景集中表现局部关系；俯拍和组合图可以使用较深景深。

不把极浅景深作为全系列要求，不强制每张摆出三层道具，也不用全局模糊替代空间调度。

**品牌布景应在已确认景别内组织。** 不为露出更多家具退成远景，也不为突出产品收成贴脸特写。

呼吸感来自主次、轮廓间隙、连续低信息区域与观看距离。白色织物和密集褶皱仍是视觉信息，不能仅凭颜色浅就算作留白。

## 材质与高频纹理纠偏

- 毛绒纤维、织物纹理和自然褶皱属于材料信息，按当前商品与观看距离真实表现。
- 保留不同材料的反光、柔软程度和受压变化，避免把皮肤、衣物与产品处理成同一种光滑表面。
- 排除无意义噪点、凭空增加的细碎纹理、密集装饰、碎高光与过度锐化。
- “画面干净”不等于消除真实纤维。
- 远景与特写采用符合观看距离的细节密度和锐度，不用全局磨皮或全局锐化统一质感。

## 工作流程

### 1. 确定共同任务与品牌落实方式

产品资产图组、人货尺度图及卖点确认后，按 [页面映射](page-patterns.md) 保留各屏目的、景别、使用关系与 PSD 框位，完成整套单案规划。动作和支点适应新品；尺度仅引用 [适用图](product-scale.md)。

每屏落实浅蓝承托、奶白无缝棚底、适用木件、柔光方向、空间与接触关系。已有方案得到认可时，仅修正与固定品牌基准冲突的环境描述，不重新分配任务或改变观看距离。

### 2. 选择并查看匹配正例

按本章选择风格案例；产品资产图组、尺度图与人物卡的实际输入按 [媒体执行](media-execution.md) 组织。每张参考职责明确，不让风格图提供新品形状、大小或指定动作。

### 3. 默认每屏一个完整方案；多案仅按明确要求启用

默认每屏一个方案，完整交代行为与支点、机位与裁切、承托、蓝白与木件安排、空间和光线；规划自检通过后按 [生成节奏](planning.md) 执行。以下差异设计与横向比较仅在用户明确要求同一屏多个备选时适用，按约定数量规划。各案具有相同的页面用途、摄影任务、景别和品牌基础，并能独立替换到同一页面位置。

差异主要来自以下方面的组合：

| 可变化的方面 | 具体内容 |
|---|---|
| 人物与产品组合 | 身体轴线、依靠方向、头枕关系、手臂围合与受力方式 |
| 承托面与家具体块 | 展开方向、可见轮廓、体块关系及与主体的衔接 |
| 摄影机观察方式 | 同景别内的观察方向与适度机位变化 |
| 前后景组织 | 前景进入路径、遮挡对象、后方距离与视觉引导 |
| 重心与呼吸空间 | 主体位置、轮廓间隙、低信息区域形态及版式衔接 |

各项变化应共同组成完整构图，不要求每案更换全部家具或改变所有变量。

每案都须交代行为与支点、机位与裁切、主体和承托面的组合、浅蓝与木件的安排、空间递进和光线。不能只把第一案设计完整，后续方案仅写相对第一案的微调。

“完整方案”指规划充分，不要求人物、产品或家具全部完整入镜。

同一种动作可以形成不同空间组织；只改表情、小物件、轻微位移或裁切，不能作为主要方案差异。

横向比较时同时确认：

- 各案都完成同一个任务；
- 各案均符合品牌基准；
- 景别和必要使用关系保持一致；
- 构图与空间组织形成真实选择。

差异不足时重新组织空间，不能通过换成远景、特写或产品展示来补足方案数量。

### 4. 核对实际提示词与参考输入

提示词简明交代：页面任务与画幅 → 有序参考职责 → 本章固定品牌基准 → 本屏动作／陈列、机位与留白 → 无字和输出要求。尺度直接指向人货图；不要再用文字重新估算。

最终提示词与实际参数的核对统一执行 [媒体提交前检查](media-execution.md)，检查写入文件并真正要发送的内容，不以规划正确代替。

### 5. 生成与审看纯摄影底图

每屏一张完整无字页面，三图与四格均在同一张图中实现；保留 PSD 留位，摄影阶段不生成标题、LOGO 或装饰文字。明确拆图时按 [版式规则](brand-layout.md) 执行。

生成后按 [基础验收](canvas-comparison.md) 对照产品资产图组、尺度图、本屏任务与品牌风格，记录实际看到的问题，再按当前 [看图节点](planning.md) 展示。首批及逐张模式的用户确认不能被 Agent 自检代替。

### 可选多案：仅用户明确要求时检查统一与选择价值

分别检查：

- **与品牌基准一致**：每案都满足适用的空间、蓝白关系、柔光、人物与材质要求。
- **与共同任务一致**：每案都能独立用于同一页面位置，保持已确认的景别和关键使用关系。
- **表现有区别**：人物组合、承托体块、观察方向、前景路径或留白形态提供真实选择。
- **执行充分**：各案均完成具体调度，实际调用没有省略共同品牌要求。

三案彼此相似，只能证明内部一致，不能证明符合品牌。三案都采用白绿配色，也不能替代与抱抱云朵社蓝白环境的对照。

### 根据问题所在层级修正

- **品牌色彩或家具遗漏**：在原景别与原方案内调整承托面、织物和木件，不自动拉远镜头。
- **景别或任务偏离**：恢复已确认的观看距离与使用关系，同时保留品牌基础。
- **空间平、退焦空泛**：调整物距、遮挡和承托体块，不只增加虚化。
- **人物摆拍或受力不可信**：调整注意力、支点、身体轴线与接触关系，不只修改表情。
- **用户要求的多案趋同**：重新组织构图和空间，不通过换摄影任务制造差异。
- **参考不匹配**：重新选择具有相容摄影关系的正例，不按页号替换。
- **局部材质或商品错误**：在整体关系成立的基础上定向修正，避免无关重构。
- **人货体量偏离**：核对适用尺度图是否实际传入、图号是否正确，以及提示词是否另行规定了大小；依图调整抱法和接触，不追加估算尺寸补救。

最终以实际成图、当前任务和匹配正例的对照为准。摄影美感、景别正确与品牌一致必须同时成立，不能用其中一项的通过抵消另一项的失败。
