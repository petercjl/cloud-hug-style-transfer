# 品牌文案与版式

在用户要求完整图文、排版，或当前待转换页确有正文时使用。无字任务按 SKILL.md 执行，不因为内置案例有文案便加字。完整正向依据见 [19 张连续定稿](detail-final-20261016.md)；需要诊断首屏图文问题时再读 [首屏对照](kv-layout-case-20261012.md)。

## 先识别本屏及整段职责

保留当前旧页的商品、已确认文字与有效证据关系，再用本品牌的摄影、字形分工和图形语言重建表达。明确标为“仅作参考”的图片才只借组织关系，不提取其中商品与参数作为本次事实。新商品不自动沿用历史系列名、款数、尺寸、面料、售后或性能文案。

品牌开场建立身份和拥抱感受；系列入口让读者理解产品归属；品类段便于比较；使用页建立人与商品的关系；信息页方便查阅；收尾回到品牌情绪。先看当前任务位于哪一段，再决定标题、摄影和信息分量。需要缩短旧页时重组信息，不只是缩放整张长图。画幅按当前交付要求与有效参考选择，不把方形主 KV 扩展成所有页面要求。

连续页面不要求每屏换骨架。定稿 07–10 持续使用“一大两小”，帮助比较同层级品类；相同边距、分隔与标题位置可保留，内部摄影根据商品改变角度与人物关系。功能转变时再改变密度与节奏，例如从 15 产品合影进入 16–18 信息段。整套统一可以包含安静、轻快、贴近、远观和信息展示。

| 品类名称：07–10 | 简明编号与名称，位置持续稳定；摄影承担主要展示 | 编号、商品名、款数从当前资料读取，不固定为四款 |
| 使用标签：12 | 短蓝色标签与黑色说明分层，图文一一对应 | 标签必须准确描述本次动作；不复制未适用的用途或功效 |
| 功能章标题与资料：16–18 | 较大的黑色功能标题、清楚的正文与参数行，服务快速查阅 | 不因“品牌柔软”把参数变成细浅小字，也不把旧参数当新商品事实 |
| 信息分组：02、18 | 服务图标、细线、浅底模块和云形编号建立秩序；保留足够行距 | 条目数与模块高度随内容，不为形式硬塞四项；政策由当次资料决定 |

“／”仅表示换行。用户锁定的文字逐字保留，按实际中文语义处理行长、标点、引号与断行；中英文按视觉重量配合，不机械同字号。文字轻重由角色决定，不能把“温柔”写成全套粗圆、全套手写或全套小细字。新文案标为提案，不能凭空增加尺寸、成分、认证、医疗或性能承诺。

## 摄影、文字和图形共同构图

生成前形成一句具体安排：第一眼先看什么，主句怎样承接人物或商品轮廓，辅助信息如何分组，图形连接哪里，哪里保持低信息。不要先完成摄影，再找空角塞标题。

01 的较大斜向摄影组、左下主句、右上轻品牌句、右下系列英文和边缘浅蓝弧面共同构图；03 以系列标题开启睡眠场景；11 的手写点缀和人物目光共用空白；16–18 用稳定列、线与模块组织资料。这些关系可重用，具体坐标和图形组合不固定。

- **图形有职责。** 线条、弧面、框形与云承担导向、分组、节奏或识别；不要求每页同时出现下划线、椭圆和云。
- **呼吸按信息判断。** 比较组间距离、阅读主次与连续低信息区域。较大的主体、近景裁切也可以成立，不统一缩小人物或空出半幅；功能页也不能为留白牺牲可读性。
- **摄影服从用途。** 抽象品牌开场可使用无居室的悬浮拥抱；日常使用则落实承托与接触；材料页对焦真实纹理；不把一种摄影手法套给整条详情页。
- **颜色不取代信息。** 蓝白与少量木本色维持品牌关系，黑色文字可承担功能阅读；商品本色和有依据的材料图片不强行改蓝白。

## 三张版式的差异

先锁定当前画幅、有效文案、原标识、商品事实和品牌摄影，再分别决定焦点、阅读路线及图文图形关系。可按素材探索摄影与文字共用动势、文字区与照片形成对照、文字与形体穿插等组织方式，不把这些例子固化成每次 A/B/C。三案的共同命题、保留项与逐案调度先按 [摄影方法论](photography-method.md) 锁定，再各自组织图文。

每案都能说清这样组织如何服务页面。只是把同一粗大标题左移、居中、右移，或换商品，不能算三种完整版式。用户明确只需局部移位时遵从该范围。按授权分别交独立成稿，不把三案合成方案墙；单页本身的一大两小或四格结构则可以保留。

## 输入与验收

实际传入当前源页／设计依据、必要商品与人物参考，以及本次需要的原 LOGO。按工具当前能力分配输入，省去重复氛围图；不硬编码历史工具上限。同一张清楚成稿可承担多个职责，必须先实际看图确认。反例仅内部诊断，不传作正向风格输入。

生成说明先写准确文案、角色、层级、断行与图文结构，再写配合的摄影、图形和保留项。沿用有字成稿时，检查当前是否其实要求无字；处理新商品时，检查历史品类、面料与规格是否被误带入。

先整幅比较第一眼、阅读路线、字体角色、图文联系及邻屏节奏，再逐字检查中文、英文、原标识和数据，最后核对商品与接触细节。比较段的有意同构可保留；无职责的重复标题与装饰需调整。不能因产品基本正确便推荐整体排版未成立的稿，也不能因成稿视觉被认可便认证其中所有事实。
