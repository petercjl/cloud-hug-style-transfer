# 抱抱云朵社风格转换

使用中文展示名 **抱抱云朵社风格转换**。用本目录内的方法和素材独立完成品牌转换，以当前使用者的明确要求为准；生成能力由必需的 `@petercjl/sealseek-media-cli` 及其规范配套 `sealseek-media` Skill 提供，品牌资料不依赖创建者的历史会话或私人文件权限。

## 运行合同与平台入口

输入是当前源页、商品资料和本次目标；输出是约定数量的独立成图及简短验收说明，或用户仅要求的规划。本 Skill 负责品牌方法、素材选择、提示词、版式和业务验收；`@petercjl/sealseek-media-cli` 负责生图服务、认证、参考图传输、任务恢复和结果下载；宿主负责命令执行、实际看图和交付。

### 入口：必需依赖检查

**每次任务先检查依赖，通过后才进入第 1 节；规划任务也遵守此入口。** 执行 `cloud-hug-style-transfer doctor --json`，核对 `dependencies.media.ok`。检查支持当前 npm 安装树、PATH 安装及显式配置的 `CLOUD_HUG_MEDIA_ROOT`；返回的 `dependencies.media.invocation` 是经过包身份核验的 CLI 调用入口，使用宿主当前 Node 运行时，可用于 Agent 管理的运行时或套件组件。

未检测到 `@petercjl/sealseek-media-cli` 时返回 `DEPENDENCY_MISSING` 并**暂停整个任务**，保留输入和进度，给出最简安装提示词：“请安装 npm 包 @petercjl/sealseek-media-cli。”等待安装并重新检查通过后，从本入口恢复。版本低于 0.6.1、CLI 无法执行、规范 Skill 缺失或合同不兼容同样暂停，按诊断修复后复查。不得以宿主内置生图、其他提供商或继续规划代替依赖通过；本入口不自动安装软件或提交生成。

通过检查后，使用返回的 CLI 入口执行 `skill source --json`，以逻辑名 **sealseek-media** 核对来源，并完整读取其当前 `SKILL.md`；相对资源从该目录解析，更新后重新加载。需要其 0.6.1+ 的当前合同：`version`、`doctor --live --json`、`capabilities --live --json`、模型查询、参考图生成 dry-run、任务提交/跟踪/恢复和本地交付。依赖输入是本 Skill 选定的提示词、有序参考图及职责、数量、画幅和授权；输出是任务 ID、状态、模型、可验证文件与错误。认证或服务不可用时暂停，由配套 Skill 处理其恢复分支；恢复后回到此入口或既有任务跟踪节点，保留任务 ID，不自动重提。

读取 [能力合同](capabilities.json) 和当前宿主适配：[Codex](adapters/codex.json)、[SealSeek](adapters/sealseek.json)、[WorkBuddy](adapters/workbuddy.json)。三者的 `media.image.edit` 统一通过上述 CLI，`media.image.inspect` 使用宿主实际看图能力；只加载当前宿主适配。缺少命令执行、看图或当前模型所需的参考图特性时，返回 `CAPABILITY_UNAVAILABLE` 或 `FEATURE_UNSUPPORTED` 并暂停。安装通过不等于已登录、拥有额度或实际生成效果合格。

按第 1–4 节理解任务与选取依据，第 5 节调用依赖执行，第 6 节实际验收；局部失败回到对应设计或执行节点。包管理采用 `cloud-hug-style-transfer` CLI 的当前 `skill source/status/install/update` 合同；两个包各自维护来源和更新，账户与凭据保存在媒体包的私有配置中。

## 1. 识别当次商品与页面任务

默认把上传的旧详情页作为**待转换源页**：其中商品就是本轮商品，保留可确认的形态、配色、材质、数量、规格、使用方式、有效卖点及文案。只有明确标为“仅借构图／竞品参考”的图片，才只借表达关系，不把它的商品或参数当成本品。

实际看图，形成简短判断：本屏让买家理解什么；原图靠什么关系成立；哪些内容须保留；品牌、人物、场景与排版如何更新。区分观察和推断，不要求使用者填长表。

| 依据 | 职责 |
| --- | --- |
| 待改源页与当次产品资料 | 商品事实、已确认文字、卖点、使用和比较关系；冲突时以明确更正为准，关键事实仍不明才询问 |
| 明确标注的外部参考 | 指定的机位、动作、构图或版式启发，不自动替代当前商品或品牌 |
| 内置最终成稿与品牌原图 | 品牌视觉、文字角色、摄影状态和连续节奏，不认证新商品的材质、尺寸、款色 |
| 已确认模特设定卡 | 以 `assets/model/character-sheet-approved-20261019.png` 统一模特身份与默认衣着；动作按当次用途，不继承卡片站姿 |

按 [当次产品事实](references/products.md) 处理商品。历史四款动物抱枕不是默认清单；新商品不套长条比例、六色数量、法兰绒或旧尺寸。源页足够清楚时可直接作为产品依据，不要求重复上传整套实拍；模糊、遮挡或关键结构不足时只补必要资料。不能从品牌案例补造参数。

保留原页有效的景别、视点、裁切、分区、信息密度和用途。未另定比例时沿用源页画幅，不因“详情页”自动改竖版。锁定布局时保留布局；开放转换可按同一信息职责优化图文关系，不擅自删卖点、改变产品或重排已确认屏序。品牌标识版位转换为本品牌；商品本体标签或包装换标依当次要求处理。

“先看／理解／规划”按该范围交付；要求“生成／转换／按规划做”或已经批准时完成约定数量，不逐张重复确认。只授权复盘或技能更新时不额外生图。

## 2. 按正文选择摄影或图文

| 当前依据 | 输出 |
| --- | --- |
| 明确无字 | 纯摄影，不加标题、说明、口号、LOGO或图形贴纸 |
| 明确要文字／排版 | 用给定内容组织完整图文；新文案标明提案，不造产品事实 |
| 未另说，源页有有效标题、卖点或说明正文 | 保留已确认内容与含义，转换字体、层级及图文组织 |
| 未另说，源页没有正文 | 默认纯摄影；“用于详情页”不自动授权加字 |

摄影署名、水印、装饰小字和孤立他牌标记不算正文，不能据此编标题。LOGO只在明确要求或源页确有品牌识别版位时使用。无字图的低信息区域属于摄影，不改成待填标题区。

图文任务读 [品牌文案与版式](references/brand-layout.md)：先定确切内容、文字角色、阅读顺序与图文组织，再安排摄影。采用原 `assets/brand/logo-blue.png` 的云形、字形、比例和中英文；品牌名“抱抱云朵社”，英文“CLOUD HUG CLUB”。“让每一次拥抱，都有柔软回应”仅在确需品牌句时取用；系列名随本轮商品，不自动使用旧伴睡系列英文。

## 3. 保持品牌，按职责决定画面

以 [完整19页定稿](references/detail-final-20261016.md) 为当前品牌正向基准，按本屏用途取图。**摄影方向（镜头任务、生活叙事方法、人物与空间调度）统一按 [摄影方法论](references/photography-method.md) 执行。** 先判断本屏及所在段落要完成什么，再安排主体分量、观看距离、裁切、动作、清晰范围和文字；不把所有页面都改成安静远景。

| 品牌维度 | 落实方法与边界 |
| --- | --- |
| 空间 | 连续低信息的白／奶白／极浅中性灰概念棚景；家具是有选择的布景，按行为取床、沙发、地毯或必要承托面。避免补出门窗、墙角、踢脚线、柜体、窗帘墙、拱门、舞台阶梯和商品展台。紧景只露必要部分；概念KV可无家具、可漂浮，不推广到使用证据页。 |
| 色彩 | 奶白与低饱和浅蓝建立品牌联系，少量木材本色增加温度；床品与沙发沿用浅蓝或选定成稿。商品保持真实颜色，不为品牌配色把新品染成蓝白。奶白物体不等于暖黄照明。 |
| 光线 | 画外大面积扩散的中性白主光；明确方向，宽缓明暗塑形，适量反射保留暗面。保持体积、自然阴影和干净背景。避免硬窗格、直射光条、无动机光斑／逆光／发光轮廓和全图泛黄；明亮不等于所有面等亮或过曝。 |
| 景深 | 用真实物距、遮挡和自然退焦建立距离。先保护应看清的产品部位、动作接触或文字；SKU及尺寸可用更深清晰范围，触感图可紧裁，情绪收尾可柔化。不强加三层道具或全局模糊，不把虚化当构图腾空。 |
| 家具与道具 | 必要时选小体量、有曲面、收腰或雕塑体块的木几等，按构图决定数量和露出范围。特写、图示、抽象KV可不用家具；不堆小摆件，不让木灯染黄环境。普通靠垫、毯子是道具，不自动算本品SKU。 |
| 模特 | 以用户于 2026-10-19 确认的设定卡为唯一当前人物标准，读 [人物与受力](references/model.md)。默认奶白长袖家居服、宽松长裤和奶白素面棉袜，可见脚部与脚踝由袜子覆盖；旧 KV 和详情页只借摄影、动作与排版，不覆盖当前身份和衣着。行为决定视线、重心、承托和表情，不固定闭眼、微笑、全脸或卡片站姿。纯产品页可无人。 |
| 质感 | 皮肤保留柔和体积与自然色差，衣物、皮肤、商品有不同反光，细节密度符合景别。避免塑料肤感、全局磨皮、脏噪点、碎高光和过锐。柔软通过接触、压陷和材料表现；面料按当次商品依据，不统一改成案例绒面。 |

呼吸感来自主次、轮廓间隙、连续低信息区域与观看距离。安静远观同时控制人物、产品和床垫／毯子整组占幅；只缩小脸却让承托面铺满仍不成立。亲密堆抱可较满，尺度展示可站立，比较页可完整展示；不规定留白百分比、每张小主体或固定产品数量。白衣、白产品和密集褶皱仍是实体信息，不能按白色像素算留白。

用一句可见安排说明设计：从何处观察、注意中心是哪处关系、承托面怎样出现、哪些区域退后。柔光、模特、蓝白木齐全只是材料条件，画面仍须完成本屏目的。

## 5. 将决定与原图实际传入生成

生成前形成简短执行依据：**本屏职责；事实与保留范围；第一眼的观看／阅读关系；原图职责；成图须出现什么才算做到。**这是内部工作依据，不增加审批表单。

按当前工具实际支持的输入机制与数量组织图片，不沿用旧工具固定上限。必要输入通常包括源页／设计参考、当次产品依据、有可见人物时的已确认设定卡、匹配的品牌正例；确需标识才加原LOGO。当前设定卡必须实际传入，不用旧案例人物代替。一图可兼多职，但必须看清对应信息；不能为凑数量假称模糊图足以约束身份或材料。

先省重复氛围、重复角度与无关历史案例，保护当前商品、人物和设计依据。无人图不用人物卡，无字图不用独立LOGO。内置图存在不等于已传入生成器；核对实际输入顺序、来源和职责，不只在文字里写文件名，不默认拼接参考总图。

- **纯摄影说明**：目的与画幅 → 原图职责 → 与用途相符的棚景、主次和观看距离 → 光线、清晰范围 → 行为、承托和接触 → 产品参考锁定。
- **完整图文说明**：目的、画幅与必要邻屏关系 → 原图职责 → 准确文案、文字角色、层级与图文组织 → 配合的品牌摄影与图形 → 人物、产品及资产保留项。

以原图锁定全部可见商品结构、比例、部件位置、材质、颜色、文字、标识和连接关系；提示词主要描述场景、机位、光线、动作与用途，由原图承载商品细节。

查实际说明有无相反要求：无字却夹带标题；安睡却强求笑容露全脸；亲密近景却一律缩小主体；尺寸展示却遮挡关键轮廓；柔软品牌却全套粗圆字。修正具体冲突，不靠末尾追加“自然、高级、有呼吸感”抵消。

调用当前适配中由 `sealseek-media-cli` 实现的 `media.image.edit`。按已加载的 `sealseek-media` 主线读取当前模型能力，用其参考图生成/编辑合同传入真实原图与精简提示词，先 `--dry-run --json`，通过后在已有生成授权范围内用 `--via sealseek --submit` 提交。模型采用媒体包当前默认值，用户明确指定时保留指定值；模型不支持本轮要求时暂停并报告，不自动换模型。保存任务 ID，按依赖合同查询、恢复、下载；提交结果不明先核对同一任务，不自动重提或增加付费生成。执行中依赖丢失或服务不可用时暂停，恢复后回到既有任务或本执行节点。保留精简实际调用记录，不向使用者倾倒完整日志。

分别要三张就交三张独立成稿，已授权数量连续完成，不自行拼成方案墙。创意备选应有真实观看或图文关系差异；比较型延展可保留同一骨架。一大两小、同构与否取决于页面，而非出图张数。

## 6. 按本屏职责验收，再连同邻屏看

实际看成图，先整幅看第一眼、品牌、人物状态、图文关系与空间，再放大查事实和细节。与承担同类职责的品牌正例比较，不能只读提示词判断通过。

1. **内容与输出**：商品有没有被换成旧款？用途、数量、比例、有无正文及LOGO符合本轮依据吗？已确认文案、参数与使用关系有没有改变？
2. **整体关系**：主次、景别、裁切、密度与清晰范围是否完成用途？近景不因较满就判错，情绪收尾不按SKU锐度验收；远观休息也不能因闭眼柔光就放过拥挤。图文看字形角色、阅读路线及文字与摄影的联系。
3. **品牌与人物**：棚景、蓝白关系、中性柔光、材料及身份是否一致？人物是否匹配当前已确认设定卡，默认衣着与素面棉袜是否一致，可见脚部及脚踝有无裸露？衣服相同不等于身份一致；动作是否有可持续支点，重量是否有承托，接触与压陷是否可信？活动与明确展示按对应行为判断。
4. **产品与文字**：结构、颜色、面料、比例、数量是否有当前依据？逐字检查正文、单位、原标识和可读性；艺术认可不抵消商品错误。
5. **连续阅读与备选**：比较段的重复是否帮助比较，跨段变化是否推进内容；三案是否真正提供选择。摄影变清晰或产品基本准确，不能替代整体设计成立。

整体成立时定向修局部；空间、状态或设计关系失败时调整对应关系，不锁住失败构图只修部件。遵守允许修改范围和数量，不默认额外跑多轮。交付如实说明仍有的关键问题；规则和规划检查不能证明实际生成效果已达标。
