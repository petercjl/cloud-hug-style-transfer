# 已知失败与修正

先找到成图中看得见的偏差，再改动引起偏差的那一项。

| 看到的问题 | 原因 | 修正动作 |
|---|---|---|
| 1. 画面平，像目录照 | 把某次纠错扩成「不准笑、只能单人、不准扬雪、焦段和距离固定」，镜头逐渐失去选择。 | 保留当张需要的动作和视线，只修出问题的元素。限制写明对象和作用范围，下一张重新决定机位与取景。 |
| 2. 影像偏硬，清晰感压过空气感 | 漏写高亮环境的调性，提示词却强调 sharp、fine detail。 | 每张提示词都写亮部略微泛白、发柔，环境轻微去饱和、阴影抬升、局部反差低、高光过渡柔和。仅用于天空、雪地和衣服暗部，保留脸上清楚的日光明暗，删掉推高清晰度的词。 |
| 3. 克制显成了被动或疲惫 | 用低头、喘气、看脚下或俯拍表达低情绪。 | 让她站定看线路，或平视前方大步走。稳重心、松肩、平下巴，保留果断动作与平静的嘴角。 |
| 4. 有日照，脸却平 | 所有图沿用同一句光位，转脸后太阳和面部的关系已变。 | 按这张脸的朝向和画面遮挡重新选太阳在哪一侧，同时保持充足的雪地反光，让阴影柔和、通透。核对鼻梁细亮线、背光侧鼻翼旁的淡柔影、通透的眼窝和受光的颧骨。 |
| 5. 皮肤油亮，像塑料 | 强日光叠加对皮肤细节的强调，脸颊和额头出现大片镜面高光。 | 保留自然暖肤色、真实质感和鼻梁、颧骨的细亮线，去掉大片油光。首张出现油亮就修该张，不把它传给后面的图。 |
| 6. 衣服描述吃掉了画面 | 反复锁定同一批结构，动作和态度被挤到末句。 | 把人物和镜头放回开头。产品只写 2–3 句，让当次产品图承担其余可见事实。 |
| 7. 动作参考的冷灰阴天或品牌参考里孩子的玩闹进入画面 | 附件混在一起，只写了「参考这些图」。 | 逐张写职责。人物参考 MC 只取身份，动作参考只取动作、重心和取景；B01 只定脸部日光，排除儿童身份、表情和穿搭。 |
| 8. 首张的肤感或光影缺陷复制到整组 | 把未经认可的生成图当成了连续性依据。 | 从参考序列移出该图，重新按镜头传入 MC 和对应 B 图。只有 madao 明确认可的成稿才可用作后续依据。已认可案例见[案例索引](approved-cases.md)。 |
| 9. 环境物件很少，雪面仍碎 | 雪地被密集颗粒、脚印和硬影切开，简化背景物件没有解决纹理密度。 | 用连续的大坡面、宽缓的亮暗变化交代雪地，只留必要的接触阴影，压低近处纹理。 |
| 10. 哑光面料变成塑料或缎面，碎褶抢眼 | 窄亮反光挤在褶尖，肩胸大面没有受光，褶谷发黑；整理褶皱时又收窄了衣身。 | 让光真正落在服装大面，给褶谷留雪地反射，以宽柔反光表现哑光面料。只整理碎褶，不改版型、不收窄、不移动口袋。 |
| 11. 写了侧前方，太阳还是在身后，脸是一层平光 | B02、B04 的逆光随笼统的「光和色」指令进入画面；全图降反差把脸压平；只写角度模型难以执行。 | 露脸必传 B01，限定环境图职责。太阳从镜头一侧的侧前方照脸，同时保持充足的雪地补光和柔和的阴影。核对鼻梁亮线和单侧淡鼻影，再定同侧雪坡亮面、身后斜影；排除发梢、肩兜亮边。后期降反差、抬暗部和去饱和只用于天空、雪地和衣服暗部。 |
| 12. 一组图里模特不像同一个人 | 身份参考在多张之间轮换，或参考里的脸太小、戴了眼镜。 | 每张人物图都实际传入同一张 MC，以卡上的三种脸部角度核对身份，不用动作参考或前一张成图替代。 |
| 13. 背景雪山清晰、抢眼，像壁纸 | 动作参考里的假山背景被带入成图。 | 只取动作、重心、取景、景别；按 B 组重建天空和雪面，远山缩小、推远、变淡、降低反差。 |
| 14. 光全部从同一侧来，画面呆板 | 没有按画面选边，把母版里的左右当成了默认值。 | 每张看脸的遮挡、转向、前景和留白，选能照亮露出脸部的一侧，在项目里写一句理由。除非 madao 指定，同组不全同侧。 |
| 15. 光变硬，衣身有硬投影，褶谷发黑，降反差和抬暗部的效果消失 | 为纠正侧后光，过度强调直射，把雪地补光降成了「适度」。 | 写明正午高位日光经高海拔薄雾柔化，周围大面积亮雪提供充足补光。让衣身的大块硬边投影变软、褶谷恢复本款颜色，保留鼻侧淡影与口袋翻盖下的短影。 |
| 16. 画面偏黄，像夕阳或胶片 | 雪、高光和肤色都用了偏暖的描述，却漏了日光色温；部分模型还会自行套用胶片调色。 | 写明中性偏冷的正午日光、干净白高光、蓝白雪面和冷蓝灰阴影。排除黄昏感、暖黄偏色、胶片调色与胶片颗粒，只有皮肤保留自然暖色。 |

第 11 条来自 2026-11-24 首图五张实测。madao 认可动作、景别和调性，但五张都是侧后光，均未获认可为成稿。
第 14–16 条来自 2026-11-24 第二次实测。
